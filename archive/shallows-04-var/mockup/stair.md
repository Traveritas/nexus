# 断梯 · 两个变体（`stair-var-1` / `stair-var-2`）

第三轮那座断梯（`stair`）的重做版，见 [README](README.md) 的「断梯」。
底本 `blender/scenes/stair.py`；两个变体各一个脚本，从它改起。第三轮那座留着不动，作对照。

- 截图：`../../.shots/stair-var-1-*.png` / `stair-var-2-*.png`（两个变体**同一批机位**，可并排看）
- 建：`node scripts/blender.cjs build stair-var-1`（`-2` 同）；检查：`node scripts/blender.cjs zfight|clip stair-var-1`
- 网页：`npx vite build --outDir dist-stair-var` 后 `?world=stair-var-1`
- 走测：`DIST=dist-stair-var node scripts/walk-stair.cjs stair-var-1`（`-2` 同）——18 个断口逐个用真实按键跳。
  断口表抄的是场景脚本 `print("[nx] jump …")` 出来的 18 行（两个变体一样）；表里没有断口数的改动。
- 机位：两个变体拍的是**同一批名字与坐标**（`spawn / first / ring2 / mid / rest / spur / crystal / down / up / far`），
  坐标由 `marks` / `jumps` 与第三轮、上一批 var-1 的截图反推（差几米，看的是同一个画面）。
  var-1 的 10 张这次重拍过一遍：岔路那处断口错位修掉以后（见上表最后一行）原来的截图已经对不上场景，
  顺便就与 var-2 对齐到同一批机位。
- 两个变体各自一个 `spawn`（＝到达点 `house`，纸的西南、朝东）、一个 `nx.sun((0.45,−0.55,0.7))`、
  一个 `nx.atmosphere("plumb", seed=3, fall_to="house", fall_at="stair", fall_y=−14)`（掉下去就回家）。
  不接进家里的网，`?world=stair-var-*` 直接进。

## 两个变体共同做的

**浮空的那些块要有个说法**（README 的判据）。两个变体都把「一块光板」换成**一截真踏步**（`chunk_kit`）：
1–3 级，锯齿侧面、斜面底，绕三个轴歪一点点；**落脚那一级的顶面仍在原来的高度**，
所以 18 个断口的高差、间距一个没动（`stones` 只是把侧偏 ±0.7 → ±0.25、自转 ±12° → ±8°/±10°，
把落点从方砖边上收回路中间）。

| 项 | 第三轮 `stair` | 这一版（两个变体同） |
|---|---|---|
| 浮空的块 | 一块光板（`box`，1.5/1.6m 见方、厚 0.5/0.45） | 一截**碎下来的踏步**：1–3 级、`span` 取原来那块方砖的边长、每级进深 `span/n`、每级升 **0.28**（≤0.3，能自动迈上去）、底下是一道斜面（厚 0.35） |
| 倒着的 | 无 | 约 1/3 是**倒过来**的（`flip`，绕本地 X 转 180°：平的底面翻上来当路，齿挂在下面） |
| 侧偏 | ±0.7m | ±0.175 / ±0.245m（`SIDE_K=0.35`） |
| 自转 | ±12° | ±8°（var-1）/ ±10°（var-2） |
| 歪 | 无 | var-1 前后左右各 ±3°；var-2 各 ±4.5° |
| 第二圈是几块 | 文档写 5 块 | **4 块**（`stones(4, …)`，按代码） |
| 总高 | 文档写 33m | **32.2m**（最后一级顶面 `top` 的 z） |
| 第二圈掉下去 | 文档写「落进虚空」 | **仍落在纸上**（x −6.65、y −2.95…7.45 都在纸的 23.5×22m 里） |
| 岔路（晶体那条）的断口 | — | **修掉一处错位**：碎段原来摆在「这一条的起跳边」上，于是第一块压在平台外沿（没有断口）、末段留了 1.5m 的空当，而记下来的断口却在别处——现在碎段放在 `edge + gap`、断口记在**这一块的远边**（同主路线的 `gap()` 写法），4 处 0.75m 的断口落在真的空当上；自转 12°·i（最大 36°）收到 3°·i（最大 9°），碎段不再被甩出落脚线 |

其余照旧：摊开的一页纸（两页 + 书沟 + 三层纸边）、正中垂下的线与大锤、头顶 34m 见方、中间开着 6m 方洞的底面、
方洞一圈框、去「高处」的传送、6×6 的歇脚平台、侧躺的一跑、倒挂的一跑、垂下的踏步串、
远处雾里那 9 截断梯、18 个断口、第一圈的安全网（掉回纸上）。

## `stair-var-1` · 吊着的断梯

> 整座断梯是从头顶那块 34m 见方的底面上**吊下来**的——像一只巨大的风铃。

**关键数值**

- 吊线：`WIRE_T = 0.15` 见方（同正中吊大锤那根 0.16；不细于 0.1，远了不闪），料 `lilac_dark/lilac`、
  `collide=False, shadow=False`（不挡人、不投影）。从 `TOP_Z = 44` 的底面垂到每块踏步上方，
  下端插进踏步 **0.1m**、上端插进底面 **0.25m**，跟着踏步歪一点（`dir_rot` 把本地 +Z 转到方向）。
- 每块 **1–2 根**：`span > 1.4` 的（1.5/1.6/1.7 的都在内）两根，挂在顶面中心左右各偏 **0.35m**；其余一根。
  12 块浮着的碎段（第一圈 3 + 第二圈 4 + 岔路 4 + 尽头那块斜板 1）→ 20 根绷着的线 + 4 根断线。
- 挂点（`anchor`）：出了底面（`CEIL_HALF = 17`）就拉回边内 0.6m；落进中间那个 **6m 见方**的方洞
  （`HOLE_HALF = 3`）里没有东西可挂，就推到洞外 0.5m。岔路尽头那块斜板的线是往外斜着拉回底面东边的。
- **断了的线**（`CUT = (2, 5)`，第 3、第 6 块）：线只剩一截，从底面垂到踏步上方 **2.4–3.6m** 就没了，
  那一截**慢慢晃**（`nx.behave(sway=2.0–3.0)`），那一块就那样悬着——读作「掉下来过」。
- 远处雾里那 9 截断梯：**每 3 截吊 2 截**（线往上拉到 `TOP_Z + 16`，没进雾里），留 1 截浮着做对比。
- 绷着的线合成一个网格（省画次数，也不会互相算穿模）；会晃的两截各自一个网格（`nx_sway` 只认网格自己）。
- 路线、断口、落点、安全网与第三轮**一模一样**：18 个断口、第一圈在纸上。

**截图**：`-spawn`（出生点第一眼：纸、往上的第一跑）、`-first`（纸上第一个断口往上看）、
`-ring2`（第二圈那 4 块浮着的碎段，每块吊着两根线）、`-mid`（第二圈中段：平台、垂下的踏步串）、
`-rest`（歇脚平台往岔路看：一束线收进头顶）、`-spur`（岔路上的第一块碎段与线）、
`-crystal`（尽头那块斜板上的晶体，吊在细线上）、`-down`（从高处往下看：线像辐条一样散开）、
`-up`（纸上往上看：头顶那块底面、方洞一圈框、四周浮着的碎段）、`-far`（雾里那几截断梯）。

**实测**

| 项 | 结果 |
|---|---|
| 18 个断口跳过去 | **18/18** |
| `zfight` | 0（78 个网格，0 对共面） |
| `clip` | 0（0 处穿模） |

（`clip` 只查「一件家具」之间；把 `route spur hang above page far` 这些前缀也交进去会报 3 处，
全是**故意的**：`above <-> wires`（线头上端插进底面 0.25m）、`spur <-> wires`（线头下端插进踏步 0.1m）、
`page <-> flight_01`（第一跑的底面比纸顶面低 5cm——第三轮的 `stair` 里就有，两个变体照旧，见「待看」）。

**待看**：头顶那块底面上有 24 个挂点，凑在中间几米里（`anchor` 把出边的、落进洞的都推回来），
从上往下看是一束辐条——是不是太密；断线那两处（第 3、第 6 块）离得远，要走到第二圈才看得见；
远处那 6 截吊起来的线只到雾里就断（`TOP_Z+16`），远看是几根从天上插下来的竖线，像不像「吊着」要看画面；
第一跑底下那道斜面比纸顶面低 5cm（`page <-> flight_01`，第三轮就有，`stair` 里一样报），
要把纸抬高 5cm 或把第一跑整体抬起来才干净——动它会连带动到第一圈的落点与安全网。

## `stair-var-2` · 碎成一段段的梯

> 这是一跑楼梯被**扯断**了：每一处跳跃平台是一截真踏步段，段与段之间连着一根细的残梁
> （像断桥露出来的钢筋），有的直、有的垂着、有的断了一半。

**关键数值**

- 不加吊线。段与段之间连一根**残梁**：`BEAM_T = 0.14` 见方（不细于 0.1，远了不闪），料同正中那根吊线，
  `collide=False, shadow=False`（不挡人、不投影）。
- 每根梁两端各**插进碎段里 0.4m**（`BEAM_IN`）、压在**路面以下 0.2m**（`BEAM_DROP`）——不挡落脚，也不和路面共面（`zfight` 0）。
  18 个断口 → 12 根直着连的 + 4 根垂着的 + 2 处断了一半的（各 2 段）。
- **垂着的**（`HANG = (3, 6, 9, 15)`，第 4、7、10、16 个断口）：梁从起跳那一头挂下去 **1.8–3.2m**，没接上对面。
- **断了一半的**（`HALF = (12, 17)`，第 13、18 个断口）：两道口子（0–0.62 与 0.78–1.0 各一段），中间空着；
  第 13 个正是第三圈那处 **2.4m** 的跳（要 Shift 快走）。
- 碎段本身比 var-1 歪得略多：前后左右各 ±4.5°、自转 ±10°，约 1/3 倒着。
- 远处雾里那 9 截断梯**不吊**（跟 var-1 做对比）。
- 路线、断口、落点、安全网照旧：18 个断口、第一圈在纸上。

**截图**：与 var-1 同一批机位——`-spawn`（第一跑，断口上横着一根残梁）、`-first`（纸上第一个断口）、
`-ring2`（第二圈：碎段之间那几根梁最清楚）、`-mid`、`-rest`（岔路上碎段与梁）、`-spur`、`-crystal`
（晶体下那块斜板；这一版晶体不吊）、`-down`（从高处往下看：一路上的梁把碎段串起来，是这一版最说明问题的一张）、
`-up`（头顶底面与四周碎段，梁连成一串）、`-far`。

**实测**

| 项 | 结果 |
|---|---|
| 18 个断口跳过去 | **18/18** |
| `zfight` | 0（73 个网格，0 对共面） |
| `clip` | 0（0 处穿模） |

（把 `route spur beam page above far` 这些前缀也交进去会报 22 处，全是**故意的**：每根梁两端各插进碎段
0.4m——`beam <-> chunk_07…19`（第二圈的方石与岔路的碎段）、`beam <-> slab_02…25`（各个平台）、
`beam <-> flight_13…29`（各跑梯）、`beam <-> side_06`（侧躺的一跑）；另有 `page <-> flight_01`
（第一跑的底面比纸顶面低 5cm，第三轮的 `stair` 里就有）。

**待看**：18 处断口里有 4 根垂着、2 处断了一半，其余 12 根是「直着连」——直的那几根远看会把浮着的碎段连成一条虚线，
像一串珠子，跟 var-1 的「吊线」是同一个方向的读法（一个从上面拉、一个在下面连），要不要再散开一点；
梁压在路面以下 0.2m，站在边上往下看能看见梁从碎段底下钻出来；
第一跑底下那道斜面比纸顶面低 5cm（同 var-1，第三轮就有）。

## 两个变体并排看

| 看什么 | `stair-var-1`（吊着的） | `stair-var-2`（碎成一段段的） |
|---|---|---|
| 浮空的块从哪来 | 头顶那块底面上垂下来的线（一束收在中间） | 段与段之间那根残梁（在脚下、在碎段之间） |
| `-ring2` | 每块碎段吊着两根线，线向上收进同一片天 | 碎段之间横着细梁，有的垂下去一截 |
| `-down` | 线像辐条从中间散开 | 18 根梁首尾相接，把整条路串起来 |
| `-rest` / `-spur` | 岔路上方一束线收进头顶 | 岔路碎段之间是梁 |
| 「掉下来过」 | 有：两处断线，只剩一截垂线在踏步上方慢慢晃 | 没有；靠「垂着的梁」「断了一半的梁」读 |

## 哪个更好

**`stair-var-2`（碎成一段段的梯）更像「一跑楼梯被扯断」这件事**：梁在**脚下**、在碎段**之间**，
把「断」和「还连着一点」同时说清楚（`-down` 那张一路上十几根梁首尾相接最有力），
也不新增一套「从天上下来的线」——世界里已经有一根吊大锤的线和一个垂下的踏步串，
再加 24 根线（var-1）会让「吊」这个说法变便宜。它的代价是梁细（0.14m），远了会读成虚线。

**`stair-var-1`（吊着的断梯）的场面更整**：一束线收进头顶那块底面，从上往下看是辐条，
「风铃」这个意象立得住，`-down` / `-up` 两张比 var-2 更有画面；两处断线（只剩一截垂线慢慢晃）也确实是这一版最好的一个点。
但 24 个挂点凑在中间几米里，近看偏密。

倾向：**收 var-2**（残梁），把 var-1 里「两处断线只剩一截垂线慢慢晃」挪过去做点睛——
比如把第 13 个断口（第三圈那处 2.4m 的跳）那根梁改成「断了一半、另一半垂下去慢慢晃」。
