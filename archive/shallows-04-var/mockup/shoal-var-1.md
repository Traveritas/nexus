# `shoal-var-1` · 浅水田（浅滩变体一）

> 一层层浅水田从东岸往湾心退下去，**每层田有自己的水位**，水从高的一层溢到低的一层。
> 人在田埂上走、在浅水里蹚。

第四轮浅滩的三个变体之一（见 [README](README.md) 的「浅滩」）。底本是第三轮的 `shoal`（[`blender/scenes/shoal.py`](../../blender/scenes/shoal.py)），
这一版把它改成「把水当内容」：水位一层一个台阶，每道田埂一个溢流口，明度从最高一层一路压到湾心。
不接进家里的网，`?world=shoal-var-1` 直接进（名字已在 `src/worlds.ts` 里：浅滩 · 浅水田）。

脚本：[`blender/scenes/shoal-var-1.py`](../../blender/scenes/shoal-var-1.py)。天 `ebb`、太阳 `(0.42, −0.55, 0.72)`（与底本同）。

## 做了什么

### 形状与边界（湾缩到约 80m）

网格 116 × 108（X −58..58、Y −54..54，1m 格），内容中心 (0, 0)。

- 湾心深水的外沿 `lagoon_r(θ) = 9 + 1.7/1.2/0.7 三个谐波`，**西边敞开**（`cos θ < −0.5` 起半径涨到 +120m → 一直是深水）。
- 四层田坎 `EDGES`，每层田约 **6.5m 宽**（东边宽、南北窄：`wide_at = 1 + 0.15 cos θ`）：

| 层 | 田面高 | 水位 | 说明 |
|---|---|---|---|
| BANK | 3.2 | 干 | 东岸，出生点与杯口 |
| T1 | 1.6 | **1.82** | 最高一层田 |
| T2 | 0.7 | **0.92** | |
| T3 | −0.2 | **0.02** | |
| T4 | −1.1 | **−0.88** | 最低一层田（离湾心最近） |
| 湾心 | −2.8 | **−1.7**（深水） | 水面 `SEA`，西边接着天边的四块大平面 |
| 孤洲 | 1.0 | — | 洲顶，绿的 |

每层水位 = 田面 + **0.22m**（蹚得过去的浅水）。**水面是阶跃的**：`water_level(x, y)` 用 `s ≥ bund_s(i, θ)` 判定，
台阶正好落在田埂上——水被田埂拢住，只在溢流口溢到下一层。相邻水位差 0.9m。
`DEEP = −1.95`：地面低过它就立一圈看不见的挡板（西边与湾心走不进去）。

### 田埂与溢流口（每道一个）

- 四道矮埂，各在上层田靠下那一边（`s = edge_at(i) + 半宽 + 0.35`），**埂顶 = 上层水位 + 0.08**（高出田面 0.30，迈得过去），厚 1.0m。
- 每道埂在 θ = **−7.0° / 2.5° / −3.0° / 9.5°** 处断开 1.16m：一段**白的水线**（0.72 × 0.44 × (上下水位差+0.10)，纹样「竖条」，`collide=False`）从上层水面落到下层水面，底下一圈白沫。
  四个口都放在出生点正西那一片，站在岸上一层一层看得见。

### 明度（这版最要紧的）

- **地面**（越低越暗越湿；干的一列偏暖、水偏冷）：`floor ink/violet_deep/violet` · `t4 ink/violet_deep/violet` · `t3 violet_deep/violet/rose_deep` ·
  `t2 violet/rose_deep/rose` · `t1 rose_deep/rose/pink` · `bank lilac/pink/pink_pale` · `cliff violet/lilac_dark/lilac` · `isle rose_deep/rose/pink + 顶面 green`。
- **水**（纹样都用 `flow`，从亮蓝一路压到近黑紫）：`w1 lilac/blue/blue_pale` · `w2 violet/lilac/blue` · `w3 violet_deep/violet/lilac_dark` ·
  `w4 ink/violet_deep/violet` · `deep ink/ink/violet_deep`。受光面取三色里的「亮」，所以每层水面上屏后大约落在 `#c3d1e6 → #8fa3c7 → #82799e → #5c5378 → #3a3350`，五档分得开。
- 田埂用 `violet/rose_deep/rose`（暗玫瑰），与冷色的水分开；崖是最暗的大块，干岸最亮最暖。

### 内容清单

| 东西 | 在哪 | 关键数值 |
|---|---|---|
| 水尺 | T1，θ=−24° | 15m（顶在 16.6），白紫相间每 0.3m 一格、每 1.5m 一道长的，顶上一点金；立在 1.5m 方台上 |

### 与底本不同的地方

- 水位从「全湾一个 SEA」改成「每层一个水位」，田埂承担拢水的角色，加了溢流口。
- 湾从约 130m 缩到约 80m；田坎的谐波从 3.2/2.0 收到 1.6/1.0（田窄了，坎不能弯得太狠）。
- 孤洲从 ri≈7.5 的陡台地改成 ri≈5.8、坡拉长到 6m 的缓丘（原来的坡 60° 走不上去）。
- 明度重排（见上），干岸/湿田/浅水/深水/崖/天各占一档。
- 圆叶从「悬在高潮线上」改成躺在各层水面上；新增浮灯；水尺从岔路方台挪到最高一层田。

## 实测

```
node scripts/blender.cjs build shoal-var-1     # → blender/shoal-var-1.blend + public/scenes/shoal-var-1.glb
node scripts/blender.cjs zfight shoal-var-1    # 0 对共面（108 个网格）
node scripts/blender.cjs clip shoal-var-1      # 0 处穿模
npx vite build --outDir dist-shoal-var1
DIST=dist-shoal-var1 node scripts/view.cjs shoal-var-1 名字:x,y,z,朝向[,俯仰] …
```

行走实测（临时 puppeteer 脚本，静态服务器指向 `dist-shoal-var1`，真实按键走）：

| # | 验什么 | 结果 |
|---|---|---|
| ① | 出生点落地、面朝西 | ok：脚底 (41.78, 2.19, 3.11)，yaw 92.9°（≈西） |
| ② | 从最高一层往西一层层走过四道田坎到最下面一层，不卡住 | ok：z 轨迹 1.60 → 0.95 → −0.20 → −1.10，一路往西 30m 不停，最后停在深水挡板前 −1.25 |
| ③ | 沿宽埂从东岸走到孤洲顶 | ok：从 (43, 17.4) 起，七段每段都落地，终点 (−4.2, 5.16, **1.53**)——站在洲顶方台上 |
| ④ | 深水处走不进去（`deep_fence`） | ok：一路往西最低只到 −1.36（湾心底 −2.8），被挡住 |

## 待看

- **出生点脚前那片水面偏空**：第一眼的下半幅是一大片平的浅水（近处 T1 的水），只躺着几片圆叶和一盏浮灯。要不要再放点东西（一小片细桩、几只浮灯、几片搁浅的叶），或者把出生点往后退、俯角抬一点。
- **宽埂偏重**：2m 宽、跟着四层水位一档档降下来，从孤洲那边看是一串很实的大台阶。它把水田从中间切开，也挡了一部分「一层层水面往下铺」的读法。要不要收窄（1.4m）或改成分段的窄桥。
- **层还是靠一点明度差**：水位差 0.9m 与溢流口是主要读法，但水面同时也有五档明暗；如果以后把水都调成一个色，层还读不读得出，要再看。
- **潮石那道 6.2m 的横纹**：站在岸上时它在头顶好几米，线是横过全湾的，但从近处看每块石头上的横纹更像「一道箍」；远看（`back` / `over`）才连成线。
- **浮灯太素**：现在是一只浮盘 + 一只灯罩 + 金顶，近看像个小白块；要不要做成有灯笼罩、有倒影的样式。
- **西边敞开的那一段**：`cos θ ∈ (−0.5, −0.35)` 之间还有田面但没有田埂（`bunds()` 跳过了 `cos θ < −0.35`），那一段的水是「没有埂的水位台阶」；要不要把田埂画满到敞开处。
- **溢流口的白水线**：`collide=False`，人可以直接从缺口走过去（蹚水），落地读作「水从这儿下去」；如果希望溢流口是「看得见但走不过去」的，要另说。
