# 浅滩 · 长条的田（`shoal-var-3`）

> 一层层平行的长田从东往西退下去，像剧场的看台；湾在最下面，是最后一级。
> 田坎笔直，但一层层错着位——有的地方两层挤在一起，有的地方一层宽成一大块。

底本是第三轮的 [`shoal.py`](../../blender/scenes/shoal.py)（水面固定、不涨落的那一版）。
这一版**只换地形生成函数**：把「离湾心深水外沿的距离」换成「从东往西的坐标」，同心环就成了一层层平行的长条。
`blender/nx.py` / `prefabs.py` / `shapes.py` / `furniture.py` / 别的世界的脚本都没动，新构件都写在
[`blender/scenes/shoal-var-3.py`](../../blender/scenes/shoal-var-3.py) 里的本地函数。

## 做了什么

### 形状：从「一圈圈」换成「一条条」

坐标换成**从东往西**：`u = 31 − x + bend(y)`，`bend(y)` 是两三米的缓弯（田坎不是死直的，南北两头微微往里收）。
每道田坎是 `u = edge_at(i, y)` 的一条南北向的线，各带自己的 `WIGGLE`（±2.5m、几个不同波长），
所以层与层**错着位**：基准 6m 宽的一层，实际在 3–11m 之间变化，有的地方两道坎挤在一起、有的地方一层宽成一大块。

| 层 | 从东往西的 u | 地面高（米） | 是什么 |
|---|---|---|---|
| 东岸 | u < 0 | 7.00 | 看台顶（出生点、杯口、花瓶在这儿） |
| T1 | 0–6 | 5.20 | 干田（**最亮**，水尺立在这层） |
| T2 | 6–12 | 3.60 | 干田 |
| T3 | 12–18 | 2.10 | 湿沙 |
| T4 | 18–24 | 0.80 | 潮湿地（刚露出水面） |
| T5 | 24–30 | −0.20 | 齐踝的水（水面下 0.2m） |
| T6 | 30–36 | −0.60 | 齐膝的水（水面下 0.6m） |
| 深水 | u > 36 | −2.30 | 湾（水面下 2.3m，走不进去） |

- 田坎半宽 1.2–1.5m：最大的那道高差 1.8m，落在 40° 上下的坡上，**上下都走得过去**（自动迈坎 ≤ 0.35m 用不上，靠坡）。
- 水面 `SEA = 0` 固定不动，水只是看的；`DEEP = −0.8`，地面低过它的地方立一圈看不见的挡板（0.5m 一格）。
- 崖：南北从 `|y| ≥ 33` 抬到 6.5–14.5m（**往西退成两个岬角**，x < −26 落进水里，把长田夹在中间）；东崖从 x ≥ 45。
  崖顶平地在 `|y| > 38` / `x > 50` 处直接不生成（站不上去，也看不出去）。
- 范围：田 x ≈ −5…45 × y −33…33（约 50 × 66m），加东岸与西边的水，整片约 90 × 70m。
- 孤洲：中心 (−24, 0.5)，半径 8.6±2.7（三条谐波），顶 1.8m（顶心微微隆起 0.3）；四周从深水里抬起来，坡约 43°。

### 配色：把明度拉开

三色明暗是「暗（背光/影子）· 中（漂）· 亮（正对太阳）」。太阳仰角 46°，**平的地面几乎都吃「亮」那一档**
（`ndl = dot(n, uSun) ≈ 0.72 > 0.62`），所以明度主要看第三色。按这个重排：

| 面 | ramp（暗/中/亮） | 平地上看到 |
|---|---|---|
| 干田 T1 | `lilac / lilac_pale / pink_pale` | 最亮（粉白） |
| 东岸 | `violet / lilac / lilac_pale` | 淡紫 |
| T2 | `violet / lilac_dark / lilac` | 淡紫灰 |
| T3 | `violet_deep / violet / lilac_dark` | 紫灰 |
| T4 | `violet_deep / violet_deep / violet` | 深紫 |
| 齐踝的水 | `violet / blue / blue` | 蓝（**水线在这里最亮**，读作水边） |
| 齐膝的水 | `violet_deep / violet / violet` | 暗紫 |
| 深水 | `ink / violet_deep / violet_deep` | 深紫近黑（西边那条亮的海天线就在它上面） |
| 崖 | `ink / violet_deep / violet_deep` | 最暗（朝西的崖面背着太阳，落到 ink） |
| 孤洲 | `lilac / lilac_pale / mist` | 白（深水里一块亮洲） |

水一律 `pattern="flow"`，`collide=False`，外面 4 块大平面接到天边。天空还是 `ebb`，太阳还是 `(0.42, −0.55, 0.72)`。

| 东西 | 位置 / 数量 | 说明 |

## 实测（`node %TEMP%/nx-shoal3-test.cjs`，puppeteer + 真实按键）

临时脚本指向 `dist-shoal-var3`（`require(os.tmpdir()/node_modules/puppeteer-core)`，Chrome `--use-angle=d3d11`），
用 `__nexus.set(x, z, −y, yaw, 0)` 与 `state()`。9 项全过：

```
ok   ① 出生点落地  Blender(36.04, 3.00, 7.00) 脚底 7.00 着地=true
ok   ① 面朝西  yaw=92.9°（90 ＝ −X 正西）
ok   ① 到达点 house 在出生点  [36.04, 7, -3, 92.86]
ok   ② 一层层走到最下面  经过的层高 7.00/5.20/3.60/2.10/0.80/-0.20/-0.60（共 7 层），最低脚底 -0.68，走到 x=-1.2
ok   ② 没有卡住（一路往西）  终点 x=-1.20，从 36.0 一路走到 -1.2
ok   ④ 深水走不进去  脚底最低 -0.68（挡板在 −0.8），5 秒里只挪了 0.00m
ok   ③ 长埂露出水面（站得住）  Blender(-2.50, -11.90, 0.30) 着地=true
ok   ③ 沿长埂走到孤洲顶  走过的最高处 2.14（孤洲顶 ≈ 1.8–2.1），终点 Blender(-24.66, 3.87, 1.95)
ok   ⑤ 走进杯口回到 house  world=house
```

② 一路朝西走 15 秒，脚底依次经过 7 道田坎（东岸 7.0 → 干田 5.2 → 3.6 → 2.1 → 0.8 → 齐踝 −0.2 → 齐膝 −0.6），
停在 x = −1.2（挡板在 −0.8 那条线上），全程没有卡住。③ 从埂面（0.30m）一路走到孤洲顶（2.14m）。
⑤ 走进东岸的杯口，world 变成 `house`。

`node scripts/blender.cjs zfight shoal-var-3` → **0 对共面**；`clip shoal-var-3` → **0 处穿模**。

## 待看

- **第一眼还是有点「平」**：太阳仰角 46°、人眼只在田面上方 1.6m，6m 宽的一层田在 30m 外只剩十几像素高，
  远处的几层会挤到差不多同一个视角上（几何上躲不开：等宽等高的层，视角收敛到田面的坡度角 ≈ 12°）。
  现在靠**坎背面那道暗线 + 矮埂 + 一列列细桩**把层读出来。要不要把东岸再抬高一截、或者在田面上多铺一层
  「暗背光」的坎线，等看过再定。
- **水尺太抢**：它必须立在最高一层，也就是出生点脚边（7–8m 远），15m 的杆子在画面右边占了一大条。
  可以缩到 11–12m，或挪到更偏北（但就出画了）。
- **潮石没做**：底本那 22 块刻横纹的潮石（6.2m 高处连成一条水平线）在这一版里换成了「一列列细桩」，
  按 `shallows-04` 的清单没放。若「从远处就看得见的强对象」还嫌弱，可以只留几块放在长埂/孤洲边上。
- **齐踝那层的水比 T4 亮**（蓝 `#8fa3c7` vs 深紫 `#82799e`），明度上有一个小台阶。读起来像「水边一条亮水线」，
  是有意的；如果嫌跳，把 `WATER["shallow"]` 的亮档压到 `violet` 就平了。
- 深水那一列（`ink/violet_deep`）在近处看很重（近黑），远看才被雾提亮。要不要整体抬半档，看别的变体定。
