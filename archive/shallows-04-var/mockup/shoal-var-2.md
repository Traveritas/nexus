# `shoal-var-2` · 退到底的海湾（浅滩变体二）

> 潮已经退到了尽头。整片滩涂露出来、裂着纹；越往下越湿越暗（干裂的东岸 → 湿沙的田 → 湾心那片最暗的干滩）；
> 水在很远的西边，只剩一条浅水与海天线。**「干」是这一版的主角**——跟另外两个变体（水多）正好相反。

第四轮浅滩的三个变体之一（见 [README](README.md) 的「浅滩」）。底本是第三轮的 `shoal`
（[`blender/scenes/shoal.py`](../../blender/scenes/shoal.py)，627 行，水面固定不涨落的那版）。
这一版只动水面与地形（**不动引擎、不做潮**）：水面从 0m 压到 **−1.6m**，湾里的深水退到画面外，
露出来的滩涂一层层裂着纹；22 块潮石上那道 6.2m 的横纹连成的水平线成了这一版的记号。

脚本：[`blender/scenes/shoal-var-2.py`](../../blender/scenes/shoal-var-2.py)。
天 `ebb`、太阳 `(0.40, −0.54, 0.86)`（比底本略高一点：崖不再把出生点那一片岸罩进影子里）。
不接进家里的网，`?world=shoal-var-2` 直接进。

## 做了什么

### 形状与边界（湾形与崖照旧，水退到画面外）

网格 190 × 180（X −95..95、Y −90..90，1m 格），内容中心 (0, 0)。湾形、崖、孤洲的位置都照底本，
只有三处动了：

| 项 | 底本 | 这一版 | 为什么 |
|---|---|---|---|
| 水面 `SEA` | 0.0 | **−1.6** | 潮退到底 |
| 深水的挡板 `DEEP` | −0.8（水面上蹚到 0.8m） | **−2.05**（水面上蹚到 0.45m） | 齐踝的水，再深就拦住 |
| 湾心的深水底 `LAGOON` | −2.2 | **−1.2** | 底本那汪深水底如今在水面**之上**：湾心是一片露出来的干滩 |
| 田坎的坎半宽 | 0.8 / 0.7 / 0.7 / 0.7 / 0.9 | **1.5 / 0.7 / 1.1 / 2.0 / 3.2** | 每 1m 网格抬不到 0.3m，上下都走得通（见「实测」②） |
| `height` 里的新项 | — | **`SEA_DROP = 5.2`**：`z −= 5.2 · 西向权重 · ss(2, 46, r)` | 出了湾心往西海底一路深下去——湾里的深水退到画面外，只剩西边远处一条海 |
| `height` 里的新项 | — | **`MOAT = 0.8`**：孤洲脚下（`d ∈ [ri+3, ri+12]`）一圈下凹 | 水退到底后洲脚还剩一圈 0.4m 深的齐踝水（洲就成了岛） |
| 孤洲 `ISLE` | 0.95 | **2.6**（顶面 2.9） | 底本「孤洲没有分量」；坡度放缓到约 40°，走得上去 |

各层的地面高（田一层层照旧，只是水面退到了它们下面）：

| 层 | 田面高 | 水面以上 | 这一版的样子 |
|---|---|---|---|
| BANK | 3.2 | 4.8m | 东岸：出生点、杯口、崖脚，最亮的一档，干裂 |
| T1 | 1.4 | 3.0m | 干田，一道道泥裂 |
| T2 | 0.35 | 1.95m | 干沙 |
| T3 | −0.15 | 1.45m | 湿沙，斑驳 |
| T4 | −0.45 | 1.15m | 潮痕那层，一道道横纹 |
| 湾心（原深水底） | −1.2 | 0.4m | **露出来的滩涂最低一层**：最暗、裂着纹 |
| 西边的海 | −2.1 … −6.4 | 水下 0.5 … 4.8m | 只看得见一条水，深过 −2.05m 走不进去 |

所以从出生点往西看：**脚下到 57m 全是干的**（岸 → 四层田 → 湾心的干滩），
再往西才是水（齐踝的浅水 → 深水 → 海天线）。

### 配色（把明度一层层拉开）

底本的毛病是「雾白 + 粉 + 淡紫，明度全在一个带上」。这一版按 6 档往下压（受光后取 `nx_ramp` 的「亮」那一档）：

| 面 | `nx_ramp`（暗,中,亮） | 受光的亮色 | 纹样 |
|---|---|---|---|
| 东岸 `shore` | lilac_dark, pink, **pink_pale** | 最亮 | 颗粒 |
| T1 `bank` | lilac, lilac_pale, **lilac_pale** | | 方砖（泥裂） |
| T2 `up` | lilac_dark, lilac, **lilac** | | 颗粒 |
| T3 `mid` | violet, lilac_dark, **lilac_dark** | | 颗粒 |
| T4 `low` | violet_deep, violet, **violet** | | 横纹（潮痕） |
| 湾心的干滩 `floor` | ink, violet_deep, **violet_deep** | 最暗的干面 | 方砖（泥裂） |
| 崖 `cliff` | violet, lilac_dark, lilac | 背光的一档 | 横纹 |
| 齐踝的水 `shallow` | violet, blue, **blue** | 全篇唯一饱和的一块 | 流 |
| 深水 `deep` | ink, ink, **violet_deep** | 最深 | 流 |

- 干的地方的「裂纹」走 `nx_pattern` 的方砖（1m 一格，每块自己的色偏，少数整块换色）与颗粒；
  近处（岸、干滩）看得出是一道道泥裂，远处并成斑驳。
- **一处偏离底稿**：稿子写「齐踝的水（暗而饱和）」，但 16 色里最暗的几枚都是灰紫，做不出又暗又饱和。
  这一版把齐踝的水放在饱和的蓝（`blue`）上——比湿沙亮一点，却是整篇唯一饱和的一块，也正好是那句
  「远处一条细细的亮水线」；明度阶梯仍是 `东岸 > 湿沙 > 深水` 往下走（`pink_pale 0.85 → lilac 0.63 →
  lilac_dark 0.48 → violet 0.35 → violet_deep 0.22 → 深水 0.11`）。

## 待看

- **田坎放平之后，一层的「台阶感」弱了**：为了让上下都走得通，五道坎的半宽从 0.7–0.9 放到 1.1–3.2
  （每 1m 网格抬不到 0.3m）。代价是 T1 那一层（8.5m 宽）有一多半变成了坡，层次靠田埂的细线和色带读，
  不再靠一道硬坎。要是更看重「一层层」的硬边，可以把坎收回去、在湾里另修一条上下坡的道。
- **齐踝的水是饱和的蓝、不是暗的**（见「配色」）——这是 16 色里的取舍，摆在一起比的时候可以否掉。
- 底本（`shoal`）里「从湾底走不回岸上」这件事，量出来是真的：底本那道 LAGOON→T4 的坎 1.75m 摊在 1.6m 上，
  1m 网格一格抬 1.1m，迈不上去（实测底本卡在 x = 23.7）。这一版把坎放平就是为它；**底本没改**。
- 远处的海底（r > 60）不画网格（水不透明），西边那条海的近岸是水面的边；水深过 −2.05m 就是挡板，
  挡板的形状跟着地形走，站远了看不出来。
- 出生点旁那两块潮石是硬摆的（种子挑不到那么近）；它们与 22 块随机潮石之间没有避让，别的世界抄这段时注意。
- 孤洲顶面（约 16 × 14m 的台地）除了石堆与晶体是空的——这一版没往上放东西，摆在一起比的时候看要不要。
