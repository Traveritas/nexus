# 下沉 · 井 · 两个变体（`descent-var-1` / `descent-var-2`）

第三轮那口井（`descent`）的重做版，见 [README](README.md) 的「下沉 · 井」。
底本 `blender/scenes/descent.py`；两个变体各一个脚本，从它改起。第三轮那口井留着不动，作对照。

- 截图：`../../.shots/descent-var-1-*.png` / `descent-var-2-*.png`
- 平面图：[`plans/descent-var-1-*.png`](plans/) / [`plans/descent-var-2-*.png`](plans/)（`tools/plan.py`，`box=-30,-30,30,30`）

## 两个变体共同修的（第三轮量过的病灶）

| 病灶 | 修法 | 结果 |
|---|---|---|
| 每段梯少 0.3m：19 级 ×0.3 = 5.4，末级到下一层台面差 0.6m，上行迈不上去 | `STEPS=20`（20×0.3 = 6.0 正好一层），每级顶面 = `z − RISE·(k+1)`（`shapes.tube` 的 `loc` 是管的**底面**，所以写成 `z − RISE·(k+2)`）；`TREAD=4.2349°`、`SPAN=20·TREAD=84.698°` 跟着重算 | 上下都走得通（走测见下） |
| 梯带比台窄 0.4m，沿整段梯内侧留一条 0.4m 宽、6m 深的槽 | `STAIR_IN = LEDGE_W = 3.0` | 梯带与台同宽 |
| 台面缺口、`BAYS`、捷径台、桥、横缝剔除区全是手算常数 | 全由 `STAIR_A` / `SPAN` 派生：`stair_range(n)`、`landing_range(n)`、`ledge_gaps(n)`、`solid_arcs(n)`、`door_angles(n)`、`free_at(n, 度)` | 上下层的洞、梯口不再打架 |
| 出生点脚前一大片白（`rim_flat` r 14.2→17，2.8m 宽） | `rim_flat` 收到 r 14.2→15.2（1.0m 宽），六圈台阶从 15.2 起（原来 17）；`RIM_OUT = R+WT+RIM_W` | 井沿窄了，脚前不再是白地 |
| 井里两只浮环（r 7.2 @ −8.5、r 5.2 @ −20.5）穿新几何 | var-1：缩进天井里（r 6.0 @ −9、r 4.0 @ −21）；var-2：挪到楼顶以上、井口以内（r 5.6 @ −1.5、r 4.4 @ −0.6） | 不穿墙、不穿楼 |
| 台面末级与下一层台面共面（新算出来的坑） | 台面在「上一层梯末级落脚的那一段」也断开（`landing_range`），末级顶面正好填上 | `zfight` 0 |

其余照旧：院子、六圈台阶与墙、东北角 64 级螺旋天梯与晶体、墙外 14 座塔、头顶三只环、
回家那汪映着天的水（`portal_home` → `house`，`at="descent"`）、每级 ≤0.3m、门洞 ≥0.8×1.9m。
两个变体各自一个 `spawn`（＝到达点 `house`，`polar(15.6, 270)` 朝北）、一个 `nx.atmosphere("lattice", grid=3, grid_lit=1, lamps=True)`（照旧原主题）、一个 `nx.sun`。都不接进家里的网。

## `descent-var-1` · 年轮

> 井壁往里，一层层长出环形巷子，像树的年轮；井心的空洞一层比一层小。

**关键数值**

- 井心空洞半径（第 1–4 层）：**10.0 / 8.5 / 7.0 / 5.5**；井底仍是 r 7 的池。每层的台面 = 环 `[空洞, 13]`。
  （README 写「每层 2 圈内台、各 3m 宽」；空洞按它给的 10/8.5/7/5.5 一层差 1.5m，所以外圈仍是 3m 的台、内圈是 1.5m 宽的环巷，第 1 层（空洞 10）只有外圈。）
- 圈墙：在第 n 层、半径 = 上一层台面的内沿（`VOID[n-1]`，即 10 / 8.5 / 7），从这层的地顶到上一层的地底，门上开在**每段实心弧的中点**（`door_angles(n)`）。
- 外圈上的隔墙：第 2–4 层各 2 道（`radial_walls(n)`，取「落脚弧」与「往下的梯弧」的中点），把**落脚的一段**与**往下的梯那一段**隔开——所以每层都要从圈墙的门进内圈、绕过去、再从另一道门回来才找得到往下的梯（第 1 层没有顶、没有内圈，是一条敞着的环，绕半圈）。
- 每层的圈：外圈（贴壁的 3m 台）+ 内圈（1.5m 宽的环巷，第 2–4 层；第 1 层只有外圈）。台面被 4 道断口切成几段，从上往下看是几圈错着开口的环。
- 梯：`STAIR_IN=3.0`、`STEPS=20`、`RISE=0.3`、`TREAD=4.2349°`、`SPAN=84.698°`；`STAIR_A = [200.0, 64.7, 289.4, 154.1, 18.8]`（逐层 +`SPAN`+140°）。
- 内容：第 1 层外圈的 5 个壁龛（各一只这口井的模型，一只比一只深）+ 一条 11m 的长洞（尽头地上方口，掉进第 2 层的圆屋）；第 2 层的圆屋（一座井的剖面模型，第二层那一道台上一点金「你在这里」）；第 3 层内圈外的一口小井（矮井圈 + 格栅 + 底上一点白）；第 4 层最暗（井壁与圈墙上一道道发光横缝 + 一座偏开井心 3m 的桥横过空洞）；另外每层的两段实心弧里各放一间小屋（井的模型 / 灯 / 落下的东西）。
- 捷径：从某层台面的里沿、在**圈墙门所在的那一段**（`door_angles(n)` 里那处）往井心跳，落进下一层内圈的同一段（落差 6m，不撞墙）；从最里一圈（第 4 层，r 5.5）的台边往井心跳，一路穿过各层的空洞落进井底的水里。

**截图**：`descent-var-1-first`（出生点第一眼：窄井沿、往下的梯）、`-top`（井口俯视，pitch −80：几圈错开口的环套着越来越小的洞，看得见井底的白）、`-l1` / `-l2` / `-l3` / `-l4`（每层的台与圈墙；l3 看得见那口小井）、`-l2in`（内圈巷子里）、`-up`（井底往上看：一圈圈的环与井口的天）、`-crystal`（螺旋梯顶的晶体）。

**实测**（`%TEMP%/nx-descent-test.cjs`，puppeteer 真按键走）：

| 项 | 结果 |
|---|---|
| 出生点落到院子 | ok（脚底 y 0.3） |
| ① 第 1 层沿梯**往下**走到第 2 层 | ok（脚底 −12.00） |
| ② 第 2 层沿梯**走回**第 1 层 | ok（脚底 −6.00）——第三轮那个 bug 的判据，过了 |
| ③ 从最里一圈（第 4 层 r 5.5）的台边往井心跳 | ok（落到井底 −30.9 的水里） |
| ④ 走进水面映着的那块天 | ok（world → house） |

**待看**：内圈的环巷只有 1.5m 宽，走起来有点挤；第 1 层没有内圈，是这一版里唯一一条敞环；圈墙/隔墙全是同一套冷紫，暗处靠描边分，三层往下可能偏糊；「从井沿往井心跳」这一条做不到（几圈台会把人接住），回家要从最里一圈的边跳——这一版的「年轮」本来就是把井心填掉。

## `descent-var-2` · 方楼

> 圆井心里砌着一座方形的楼，一层层错着转 90°；楼与井壁之间剩下一弯月牙。

**关键数值**

- 楼板两边 **12.6 × 12.0m**（略长方的方，好让「转 90°」看得出来），楼心偏开井心 **1.6m**，墙厚 0.4m、楼板厚 0.5m。
  （README 写的是「边长 12–13、偏开约 2.5m」；偏开取到 2.5m 时楼的角会伸到 r 10.4，压住井壁的台、挡住梯口，所以把偏开收到 1.6m、边长收到 12.6×12.0，楼的角最远 r 9.92，正好不碰台 r≥10。）
- 每层绕井心转 90°：`BT_A = [240°, 330°, 60°, 150°]`；楼心所在的角最远到 **r 9.92**（不碰井壁的台 r≥10，所以楼梯、台面都不打架）。
- 楼有三层（第 1–3 层，`z −6 / −12 / −18`），第 1 层顶上是天（矮墙 3.5m），第 2、3 层顶上是上一层楼板（墙高 5.5m）；**第 4 层楼忽然收进去**，只剩中间一块 5×5 的板（`bld4_pad`），露出白的井底与池。
- 方天井：第 1、2 层的楼板中间开一口 **2.4×2.4** 的方洞，洞落在**井心**上（本地 x = −`OFF`），上下两层对齐——从上往下看，圆井口里一个转着的方，方里一口对穿的洞，第三层往下楼占满、井底不再看得见。
- 门：楼的两面 ±x 墙上各开一个 1.4m 的门，朝月牙；楼离井壁的台还有一截（近的一侧 7.9m、远的一侧 4.7m，中间隔着那弯月牙的坑），所以每道门前补一块**扇形的台**（`thresholds(n)`，从墙外沿跨到 r=10，接上井壁的台）——人沿井壁的台走，从月牙处的门进楼，楼里是隔墙隔出的巷子与两间小屋，穿过楼从对面的门出来、再过门前那块台回到月牙。
- 梯：同 var-1（`STAIR_IN=3.0`、`STEPS=20`、`TREAD=4.2349°`、`SPAN=84.698°`、`STAIR_A` 同）。
- 内容：井壁上的 5 个壁龛照旧；楼里第 1 层放两只这口井的模型、第 2 层一角一间圆屋（一座井的剖面模型、第二层那一道台上一点金）、第 3 层地上一口小井（矮井圈 + 格栅）；第 2、3 层楼的墙上各几扇**亮着的窗**（发光横缝），第 4 层井壁上一圈横缝。

**截图**：`descent-var-2-first`（出生点第一眼：井口里一个转着的方，头上两只环）、`-top` / `-bird`（井口俯视与鸟瞰：圆的井口里套着方）、`-l1`（月牙、门前那块台、楼的墙与亮着的窗）、`-l2` / `-l3` / `-l4`（每层：楼的墙、门、梯口；l4 是楼收进去、露出井底）、`-room2`（楼里的圆屋）、`-up`（井底往上看：楼收进去后露出的那块板与井口的天）、`-crystal`（螺旋梯顶的晶体）。

**实测**：

| 项 | 结果 |
|---|---|
| 出生点落到院子 | ok（脚底 y 0.3） |
| ① 第 1 层沿梯**往下**走到第 2 层 | ok（脚底 −12.00） |
| ② 第 2 层沿梯**走回**第 1 层 | ok（脚底 −6.00） |
| ③ 从月牙的台走进门前那块台、进门、穿楼、从对面的门出来又回到月牙 | ok（脚底落在对面台外沿，没掉进月牙的坑） |
| ④ 从第 4 层台里沿往井心跳 | ok（落到井底 −30 的地上） |
| ⑤ 走进水面映着的那块天 | ok（world → house） |

**待看**：楼比井心大一圈（角到 r 9.92），月牙最窄处只剩 2.3m 左右，走起来贴着墙；门前那块台是补出来的（远的一侧那道有 5.3m 长，跨过整个月牙），要不要把它做成一座「桥」再看；楼里第 1、2 层的天井（2.4×2.4）是个 6m 深的洞，走到边上会掉下去（当捷径用，没做栏杆）；圆屋只有 r 1.8，偏小；楼墙上的窗只有第 2、3 层有；「从井沿往井心跳」这一条也做不到——楼把井心填满了，回家要从第 4 层（楼收进去那层）往下跳，或者走梯下到底。

## 哪个更好

**`descent-var-1`（年轮）更像这个世界**：几圈错着开口的环套着一个越来越小的洞，从上往下看就是「年轮」本身；每层要绕进内圈再绕出来才下得去，走的动作跟「一圈圈往下、说不清为谁而修」的调子对得上；台面 3m、内圈 1.5m，尺度比方楼舒展。它的代价是「从井沿一跳到底」没了（本来就该没有）。

**`descent-var-2`（方楼）的对比更强**：圆的井口里一个转着的方、月牙里的暗、楼墙上几扇亮窗、最后一层楼收进去露出白的井底——几个画面比 var-1 更「一眼认得出」。但楼把井心填满以后，井的竖向感弱了，人一直在月牙那条窄缝里绕，楼里的小房间也偏挤（圆屋只有 r 1.8）。

倾向：**收 var-1**；var-2 里那几扇「亮着的窗」和「最后一层楼收进去」的做法可以挪过去当点睛。
