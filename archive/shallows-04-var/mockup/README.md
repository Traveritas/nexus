# 浅梦 · 第四轮（Shallows · round 04）

第三轮（[`shallows-03/`](../shallows-03/README.md)）的四个世界——**下沉 · 井、浅滩、花房、断梯**——做出来了但都不太好。
这一轮不重排阵容，只把这四个世界**各做几个变体**，摆在一起比，挑一个（或各取一部分）再收进家里。

**变体都是能走的原型**，不是白模：`?world=<id>` 进去，截图在 `.shots/<id>-*.png`，平面图在 [`plans/`](plans/)（由 `tools/plan.py` 生成）。
命名：`<世界>-var-<n>`，如 `descent-var-1`。第三轮那四个（`descent` / `shoal` / `glasshouse` / `stair`）留着不动，作为对照。

## 下沉 · 井（`descent`）

> 一口圆井，一圈圈往下走，越往下越暗；井底却是白的、亮的。台阶一丝不苟，却没人说得清它为谁而修。

现在的样子：井内半径 13m、壁厚 1.2m、每 6m 一层、五层到 −30m；每层沿井壁一圈 3m 宽的台，一段 19 级弧梯贴壁下到下一层（下一段在 140° 之外）；井口在下沉的圆院里（六圈台阶、6m 高的墙、墙外一圈塔）；东北角一道 64 级螺旋梯升进天里，顶上一枚晶体。内容：第一层五个壁龛（各放一只这口井的模型）＋一条 11m 的长洞（尽头地上方口，掉下去落进第二层的圆屋）、第二层圆屋（一座井的剖面模型，标着「你在这里」）、第三层小圆屋（地上又一口盖着格栅的小井）、第四层最暗（井壁上一道道发光横缝、一座偏开井心 3m 的桥）、井底白的（三级台阶落进一汪浅水，水面映着井口）。

两个变体共同要做的：

- **修楼梯**：每级顶面 = `z − RISE·(k+1)`；级数取 20（20 × 0.3 = 6.0 正好一层），`TREAD` / `SPAN` 跟着重算（`SPAN = 20·TREAD`），台面缺口、`BAYS` 的角度、捷径台、桥、第四层横缝的剔除区**全部由新的 `STAIR_A` / `SPAN` 派生**，不再留手算常数。上下都要走得通（上行每级 ≤ 0.3m）。
- **梯带与台同宽**（`STAIR_IN = LEDGE_W`），不再留那道 0.4m 的槽。
- 出生点脚前那一大片白（`rim_flat` 太宽太平）收一收：井沿窄一点，台阶从更近处开始。
- 井内那两只浮环（r 7.2 @ −8.5、r 5.2 @ −20.5）会跟新几何打架：挪进留出来的天井里，或改成绕井心的环。

**`descent-var-1` · 年轮**

- 立意：井壁往里，一层层长出环形巷子——像树的年轮。每层 2 圈内台，各 3m 宽，圈与圈之间是墙，墙上开的洞上下层错开，要绕到某处才下得去。
- 第一眼（出生点朝北，同现在）：一圈矮井沿，往下一段段弧梯；**井心不再是空的**——几圈台环套着一个越来越小的洞，洞里透出下一层的暖光。
- 形状：内圈逐层收小（r 10 → 8.5 → 7 → 5.5 → 井底仍是 r 7 的池），每层的环台被 4–6 道径向短墙切成几段，段与段之间靠「内圈的一处缺口」相通；从上往下看是几圈错着开口的环。
- 内容：第三轮那些房间（壁龛、长洞→圆屋、小井、横缝、桥）**搬进巷子里**，另外每层多两间小屋（放东西：井的模型、灯、落下的东西）。井底保留白与池。
- 边界与出入口照旧：院子、螺旋天梯与晶体、塔、环；回家＝井底水面上那块天。

**`descent-var-2` · 井里砌的方楼**

- 立意：圆井心里砌着一座**方形**的楼，一层层错着转 90°；楼与井壁之间剩下的那弯月牙，就是从井口看得见的大坑。
- 第一眼：圆井口里一个**转着的方**，一层一层错开；月牙处是暗的，楼的每层有几扇亮着的窗（发光横缝）。
- 形状：方楼边长约 12–13m，中心偏开井心约 2.5m，每层绕中心转 90°；人沿井壁的台走，从月牙处的门进楼，楼里是巷子与小房间（方形的迷宫），穿过楼到对面又回到月牙。井口那圈圆与楼顶的方，是这个世界唯一的「秩序 vs 秩序」。
- 内圈的空洞：只在上两层留下（月牙），第三层往下楼占满，**井底不再看得见**——直到最后一层楼忽然收进去，露出白的井底与池（对比）。
- 内容：壁龛留在井壁上；长洞、圆屋、小井、横缝搬进楼里（楼里的房间比井壁上的洞更像「给谁住的」）。
- 其余同 var-1。

## 浅滩（`shoal`）

> 一层层往下退的浅水田，湾心一汪蓝水、一座孤洲。

现在的样子：海湾约 130m（网格 190×180），东岸高 3.2m，往西一层层退下去（T1 1.4 → T2 0.35 → T3 −0.15 → T4 −0.45 → 湾心 −2.2），北东南三面崖（9–14m），西边敞开、深水是边；湾心一座孤洲（顶上晶体）、一根 15m 的水尺、22 块刻着横纹的潮石（横纹连成空中一条水平线）、一片宽埂（带细桩）从东岸伸到孤洲、半路一条岔路到死胡同方台、北边几处水洼、孤洲西边一座闸（往深水里去的台阶）、水面上二十来片圆叶。回家＝东岸嵌在地里的杯口；花房＝北边一只插花的大瓶；沁泫池＝闸的最下一级（世界还不存在）。

**这一轮的三个变体都不动引擎**——见下面「引擎里没有的」。

**`shoal-var-1` · 浅水田**

- 立意：把「水」当内容。一层层浅水田，**每层水位不同**，水从高的一层溢到低的一层（每道田坎一个溢流口，挂一道细白的水线），人在田埂上走、在水里蹚。
- 第一眼：站在最高一层田埂上朝西：一层层水面往下铺开，每层一道溢流的白线，最远处一条亮的海天线；脚边田里躺着几片圆叶、一盏浮灯。
- 形状与边界：湾缩到 70–80m；同心，但层的读法靠**水位差 + 溢流线**（不是靠颜色深浅）。西边远处的深水仍是边；东北南三面崖。
- 内容：水尺（15m）、22 块潮石（那道 6.2m 的横纹读作「水曾经到过这里」，比现在有力）、孤洲、闸、圆叶（**躺在水面上**，不再悬着）、浮灯、埂与岔路。
- 出入口照旧：杯口回家、大瓶去花房、闸去沁泫池、晶体在孤洲顶。

**`shoal-var-2` · 退到底的海湾**

- 立意：潮已经退到了尽头。整片滩涂露出来、裂着纹；越往下越湿越暗（干裂的岸 → 湿沙 → 齐踝的水）；水在很远的西边，只剩一条浅水与海天线。
- 第一眼：站在东岸朝西：一大片干裂的滩涂一层层退下去，远处一条细细的亮水线；**头顶一条水平的横纹线**——22 块潮石上的横纹连成的那条，此刻高出头顶好几米。
- 形状与边界：同现在的湾形与崖，但水面从 0 退到 −1.6 左右（露出的田坎更多、更宽）；西边远处的浅水（深了走不进）＋崖。
- 内容：潮石与横纹线（这一版的**主角**，从哪儿都看得见）、水尺、孤洲（在最下面一层水里，顶上一枚晶体）、闸（露在干滩上，往下走 6 级才进水）、圆叶（搁浅在滩上）、水洼（干了的、裂的）、干滩上的细桩与脚印似的东西（纸片）。
- 出入口照旧。

**`shoal-var-3` · 长条的田**

- 立意：连形状一起换——不是一圈圈围着湾心的同心环，而是**一层层平行的长田**，从东往西退下去，像剧场的看台；湾在最下面，是最后一级。
- 第一眼：站在最高一层，前面一层层长条的水田往西退下去，田坎笔直但错着位，最下面一汪水与一座孤洲。
- 形状与边界：约 90 × 70m 的长条；东西向一层层（每层 6–8m 宽），南北两头收到崖里；西边是水与海天线。
- 内容：长田里的圆叶与浮灯、田坎上的细桩（一列一列，读作尺度）、水尺（立在最高一层）、孤洲（在西边水里，晶体）、闸、一条从南岸斜穿过去的长埂（比现在的宽埂更长、更直，是这一版的动线）。
- 出入口照旧。

## 花房（`glasshouse`）

> 三间歪着的玻璃房坐在一块石台上。只有屋里有阳光；玻璃外面一圈巨大的花之装置暗在影子里，看得见、走不到。

现在的样子：A 大间 13×8.5m、B 高间（平行四边形，屋脊从 6.8 抬到 10m，沿东墙一道楼梯上到 3.9m 的回廊）、C 低间（六角形，下沉 0.9m，当中一池浅水与一朵莲），两条短廊连着；头顶 28m 一整片只投影的顶，只在三间正上方顺着太阳开洞；屋里塞满花（`bloom` 的 rosette / lotus / blade / drift），4 株 `blade` 走近会张开；玻璃外一圈 11 朵 size 6–13 的巨花（暗的、走不到）。

两个变体共同要做的：

- **玻璃**：按窗棂把每段墙的玻璃切成**一格一格**（每格一块、错开 1cm），把 `ghost` 的最浓提到 0.35–0.5、近处推远（约 `(0.45, 1.0, 6.0)`），色板仍压在蓝白一列（可以加一档冷色）；目标是屋里能读出「这里有一层玻璃」，又还看得见外面。
- **外面那片受光带**：收窄顶上的开洞（别用 `f+1.6` 那一层往外扩），让石台外立刻进入影子，跟设定对上。
- **花不互穿**：第三轮的花在原样时相邻瓣就已经互穿（`blade` 的根部半径 0.06·size 小于相邻瓣半宽之和）。两个变体都要在自己场景脚本里重写一版 `blade`（根部半径、瓣宽、瓣数、朝向调开），做到原样与张开都不相交。
- **细节**：B 的回廊（3.9m 高）加栏板；A 的东半与南半（约 110㎡ 里的空处）与 C（约 57㎡）放东西；莲重做（现在读成一堆碎片）；`a_drift` 常转会让影子图每帧重画，去掉或改慢。

**`glasshouse-var-1` · 不动的花**

- 删掉全部 `nx.pose`：没有动态。花重新设计成静态的——少瓣、轮廓清楚、有茎、朝向有变化；花床做出层次（高矮、开的/没开的/落下的），落瓣铺在地上当记号。
- B 里那株 4.6m 的巨花缩到 3.0–3.2m，并离回廊柱子远一点。
- 走近张开的那个「会动」的看点，用别的东西补：光斑扫过、或者一株开得特别大的（静态）。

**`glasshouse-var-2` · 会开的花（修好）**

- 保留走近张开：`rot` 的符号改成**向外**，铰链在瓣的根部，张开后瓣尖朝外上方（不越过花心）；瓣与瓣、瓣与花床/地板/柱子逐对验过不相交。
- 一株一组（照旧），触发半径 2.2–2.6m，张开 1.6–2.4s；张开时花心露出一点亮色（金/白），让「开」看得更清楚。
- 挪开的：`a_bud1` / `a_bud2` 彼此拉开（现在相距 3.2m、半径 2.6m，站中间两株一起开），`b_tall1` 离柱子与墙。

## 断梯（`stair`）

> 从一页摊开的纸上起来的一座楼梯，断成一截一截，绕着中心盘三圈往上；掉下去就回家。

现在的样子：三圈方形螺旋（约 17.4 × 18.7m、0 → 32.2m、18 个断口），头一圈断口都在纸（23.5 × 22m）上方；路线里有 7 块浮着的方石（第一圈 3 块 1.5m 见方、第二圈 4 块 1.6m 见方，各高 0.5/0.45m、间隔 1.0m）、一跑侧躺的（踩平的侧面走）、一跑倒挂在头顶（从底下钻过去）、转角旁从头顶底面垂下一串慢慢荡的踏步（够不着，只是看）、6m 见方的歇脚平台（外侧四块方石伸出去，尽头斜板上浮着晶体）、第三圈中间一处 2.4m 的跳（要 Shift）、最后几级越往上越薄越稀、头顶 44m 一块 34m 见方的底面（正对最后一级开着方洞，一枚慢慢起伏、转的大锤从它上面吊下来）；远处雾里浮着 9 截斜的、倒的断梯。回家＝掉到 −14m 以下；去高处＝最后一级上方。

两个变体共同要做的：**浮空的那些块要有个说法**。另外顺手把文档与代码的出入改对（第二圈是 4 块方石不是 5 块；总高 32.2m 不是 33m；第二圈方石掉下去仍落在纸上，不是虚空）。18 个断口仍要**用真实按键一个个跳一遍**（高差 ≤ 0.9m、间距 ≤ 2m），第一圈的安全网（掉回纸上）保留。

**`stair-var-1` · 吊着的断梯**

- 立意：整座断梯是从头顶那块底面上**吊下来**的——像一只巨大的风铃。浮空的每一块都用一两根细线吊着；有几处的线断了，只剩一截垂线在踏步上方慢慢晃，读作「掉下来过」。
- 做法：细线用现在那根吊大锤的线（0.14–0.16 见方、`lilac_dark/lilac`、不挡人不投影）；线从 44m 的底面垂到每块踏步上方，跟着踏步歪一点。踏步本身换成「一跑楼梯碎下来的一截」（2–3 级真踏步，带锯齿侧面与斜面底），不再是光板。
- 远处雾里那 9 截断梯也吊起来（或留几截浮着做对比）。
- 大锤、垂线、垂下的踏步串都保留——它们本来就是这个世界的调子，这一版把浮空的东西也收进这个调子里。

**`stair-var-2` · 碎成一段段的梯**

- 立意：这是一跑楼梯被**扯断**了。每一处跳跃平台是一截真踏步段（1–3 级，有锯齿、有斜底），段与段之间连着一根细的残梁（像断桥露出来的钢筋），有的直、有的垂着、有的断了一半；碎段各自绕三个轴歪着。
- 做法：不加吊线；残梁用细长的方块（≥0.1m，别太细，远了会闪），两端接到碎段上；歪的角度要够小，别挡住跳跃落点。
- 第一圈的碎段仍在纸上方（安全网），第二圈开始才真正悬着。
- 其它照旧：纸、垂线与大锤、头顶底面与方洞、最后一级的亮踏步、歇脚平台、藏着的角与晶体、侧躺的一跑、倒挂的一跑、垂下的踏步串。

## 引擎里没有的

- **潮**：`docs/blender.md` 与 [`shallows-03`](../shallows-03/README.md) 里写的 `nx.water` / `nx.tide`（水位涨落、蹚水变慢、深过 0.55m 走不进）**引擎里并没有**——`blender/nx.py` 里没有 `water()`，`behave()` 也没有 `tide`；第三轮重做浅滩时改成了「水面固定，不涨落」，设计说明没跟着改。这一轮的三个浅滩变体都**不靠潮**（`shoal-var-1` 用「每层水位不同」代替），要不要把潮做成引擎功能（水面 mesh 随时间上下 + 按水深挡人，要动 `src/level.ts` / `player.ts`），等这一轮挑完方向再定。
- 变体**都不接进家里的网**：没有回家的传送物接到 `house` 之外的地方，靠 `?world=<id>` 直接进；彼此之间也不相连。

## 怎么看

```
node scripts/blender.cjs build descent-var-1      # 搭场景 → blender/descent-var-1.blend + public/scenes/descent-var-1.glb
npx vite build --outDir dist-descent              # 各人用各人的构建目录，几个人同时跑不打架
DIST=dist-descent node scripts/view.cjs descent-var-1 井口:x,y,z,朝向 …
node scripts/blender.cjs zfight descent-var-1     # 共面（闪）
node scripts/blender.cjs clip descent-var-1       # 穿模

blender -b blender/descent-var-1.blend --python mockup/shallows-04/tools/plan.py -- descent-var-1 0 -6 -12
                                                  # → plans/descent-var-1-plan.png（俯视）与 -z0/-z-6/-z-12.png（按层切一刀）
```

`tools/plan.py` 用 Workbench 渲平面图，按色板给每块上色（`nx_pal` / `nx_ramp` / `nx_color`），给了 z 就用相机的近/远裁剪面当剖切面，只画那一层——像一张建筑平面图。
