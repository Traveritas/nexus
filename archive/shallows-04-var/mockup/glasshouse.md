# 花房 · 两个变体（`glasshouse-var-1` / `glasshouse-var-2`）

第三轮那三间玻璃房（`glasshouse`）的重做版，见 [README](README.md) 的「花房」。
底本 `blender/scenes/glasshouse.py`；两个变体各一个脚本，从它改起。第三轮那间留着不动，作对照。

- 截图：`../../.shots/glasshouse-var-1-*.png` / `glasshouse-var-2-*.png`
- 建：`node scripts/blender.cjs build glasshouse-var-1`（`-2` 同）；检查：`node scripts/blender.cjs zfight|clip glasshouse-var-1`
- 网页：`npx vite build --outDir dist-glasshouse-var` 后 `?world=glasshouse-var-1`
- 两个变体各自一个 `spawn`（＝到达点 `house`，花瓶前，照旧）、一个 `nx.atmosphere("blank", grid=3, grid_lit=1, shadow_out=True, shadow_reach=50)`、一个 `nx.sun`。
  都不接进家里的网，四个出入口与到达点照旧（花瓶 → house、北墙玻璃门 → sunpatch、一杯水 → shoal、长影 → longshadow）。

## 玻璃：改前 / 改后

| | 第三轮 | 这一版 |
|---|---|---|
| 分格 | 每段墙一整块（山墙那段 5 点）、每面坡一整块、六角顶每边一整块 | 每段墙按窗棂切 `ceil(段长 / 1.45)` 格（山墙那段落在屋脊拐点的格子多一个顶点）；每面坡按椽条切 `ceil(坡长 / 1.45)` 格；六角顶每边 2 块；门楣以上的玻璃也分格 |
| 块数 | 43 块 | **151 格** |
| 错开 | 无（相邻格共面） | 每格沿墙（坡）法线错开 ±0.8cm（`Room._shift`，法线按面取、朝上） |
| `nx_ghost` | `(0.22, 2.5, 9.0)` | `(0.45, 1.0, 6.0)`——远处 45% 的像素、1m 内散掉 |
| 色板 | `nx_pal=blue_pale,white` | `nx_ramp=("blue","blue_pale","white")`（暗蓝 / 淡蓝 / 白，仍压在蓝白一列） |
| 影子 / 碰撞 | `shadow=False, collide=False`（照旧） | 同 |

一格一块之后，每格各带自己的轮廓线——**这是「读得出玻璃」的主因**：远处看是蓝白一列的一格格窗，走近（<1m）整片散掉，跟「玻璃是虚像」的设定一致（`-glassnear` 是贴到 1.2m 处拍的，那面墙几乎已经没了）。

## 顶上那片只投影的顶（`canopy()`）

`CANOPY_Z=28`、`CANOPY_EXT=52`、0.5m 的格、`nx.shade` 不变；只把 `hole()` 从

```python
for zz in (f, f + 1.6):                      # 第三轮：多测了 1.6m 那一层
    if inside((x - SUN.x * kk, y - SUN.y * kk), pts, 0.35): return True
```
改成
```python
if inside((x - SUN.x * (CANOPY_Z - f) / SUN.z, y - SUN.y * (CANOPY_Z - f) / SUN.z), pts, 0.0): return True
```

受光的地面从「房间 ∪ 房间往北/西挪 2.1m」收成「房间本身」——石台外立刻进影子。鸟瞰图（`-bird`）里
第三轮那圈贴着石台外缘的亮边没有了。

## `glasshouse-var-1` · 不动的花

> 三间玻璃房里全是不会动的花；只有太阳在动。

- **没有动态**：`nx.pose` 一个都没有，`a_drift` 的常转也去掉（换成静态浮着的几片落瓣）。
- **花床分层**：北床（7.0×1.7，一朵开的 + 一株没开的 + 一朵三层莲）、岛床（4.0×2.6，莲 + 没开的）、
  东北床（3.6×1.2，一朵开的）、南床（3.6×1.4，没开的 + 开的）——高矮、开的 / 没开的 / 三层莲各有；花床高度都是 0.4，花心高低靠茎。
- **走近张开的看点换成别的**：大间东南一株**开得特别大的静态花**（`a_big`）——1.5×1.5 的花台上 2.2m 的绿茎，
  四片瓣张开到 52°，顶到 3.8m；脚下围一圈落瓣当记号（`a_fall` 的第二组）。从出生点（花瓶前 2.1m，朝东北）
  看过去它正好在正前方。
- **A 的东半与南半**（原来约 40㎡ 空地板）：铺了 10 片落瓣（`fallen()` 自动避开墙与花床）、一株大花、一张南床。
- **C**（原来 57㎡ 除池 + 莲 + 一杯水 + 影子外几乎空）：西南加一张矮床（一株没开的 + 一朵开的）+ 6 片落瓣。
- **回廊加栏板与金扶手**：西边（敞开的长边，4.4m）、北头、东边各一块 0.74m 高的栏板 + 0.14m 的扶手，
  南头留出楼梯口（只挡 0.9m 一段）；四块首尾相接、只共一条边（叠了会共面闪）。
- **B 里那株 4.6m 的巨花**：`b_tall1` 缩到 **3.0m**，挪到本地 (2.3, 3.0)（离回廊柱子 4.4m、离西墙 1.96m、离楼梯 2.5m）。

## `glasshouse-var-2` · 会开的花（修好）

> 走近，没开的花从根部把瓣向外掀开，花心里那点金亮起来。

- **`rot` 的符号改对了**：`nx.pose(p, …, rot=(0, +open, 0))`。第三轮写的是 `−38`，与瓣本身的 `−lean` 同向，
  等于把瓣再往里推 38°——越过竖轴倒向另一侧，五片瓣的中轴全过花心。现在正角度是**向外**：
  瓣的倾角从 `tilt` 变成 `tilt + open`，铰链在瓣自己的根部（物体的原点就在瓣根），瓣尖朝外上方。
- **花心露出亮色**：花心原样时缩到 0.31 倍（藏在瓣里），张开时放大到 1 倍（`nx_pose_scale`）；
  材质是金、`emit=0.9`。`-tall1-close` / `-tall1-open` 两张一对照就看得出。
- **五组**（一株一组）：`a_bud1`（1.6m，开 24°）、`a_bud2`（1.2m，开 30°）、`b_tall1`（3.1m，开 14°）、
  `b_tall2`（2.4m，开 14°）、`c_bud`（1.2m，开 30°）。触发半径都是 **2.2m**，张开 **2.2s**。
- **挪开**：
  - `a_bud1`（−3.0, 2.7，北床）与 `a_bud2`（−1.1, −1.6，岛床）相距 **4.70m > 2×2.2**——站中间不会两株一起开
    （第三轮相距 3.2m、半径 2.6m，站中间两株一起开）。
  - `b_tall1` 缩到 3.1m，挪到本地 (2.7, 2.4)：离西墙 2.37m、离楼梯 2.1m、离南墙 2.4m；张开的半径 1.85m，
    四面都留 0.2m 以上。
  - `b_tall2` 挪到本地 (2.3, 6.9)：离回廊柱子（本地 4.25, 6.96）最近的一角 1.84m，张开的半径 1.43m。
  - 五组两两相距都 ≥ 4.4m（`poseinfo.py` 逐个算过）。
- **`a_drift` 改慢**：`spin=2.5°/s`、`bob` 0.08–0.2，并给它 `nx_shadow=0`（不进影子图，所以影子图不必每帧重画）。
- 玻璃、canopy、花床分层、落瓣、栏板与金扶手、外面的花：同变体一。

**截图**（`../../.shots/glasshouse-var-2-*.png`）

- 与 var-1 同名的九张（`-spawn` / `-rooma` / `-roomb` / `-roomb2` / `-croom` / `-glassout` / `-glassnear` / `-outside` / `-bird`）
- **原样 / 张开同机位对照**（`%TEMP%/viewpose.cjs`：先把人挪到触发半径外等它合上，再挪回机位立刻截一张、等 3 秒再截一张）：

  - `-tall1-close` / `-tall1-open`：机位 (11.742, 2.85, 0)，朝 180，俯 14 —— `b_tall1`（3.1m）张开，中间一根金的花心

## 待看

- **玻璃 45% 是否太浓**：`-glassout` 里那面东墙已经读得出一层蓝白的膜；若嫌糊，把 `ghost` 收到 0.35
  （`GLASS` 里一个数）。反过来若还嫌淡，可以把格子的轮廓交给更密的窗棂（现在每格 ≤1.45m）。
- **`nx_lit_only` 这一版没用**：试过在玻璃上想的两种用法都不成立——屋里的墙面几乎全在光里（顶的洞就开在房间正上方），
  `lit_only` 的玻璃整片都会显形，等于没筛；要做「只有被太阳扫到的那几格显形」得让洞跟着太阳走（`sun_turn`），
  这一轮没做。**这一条是「想过的」，不是「量过的」。**
- **花心那根金柱**：`emit=0.9` 在光里是亮金，暗处不压——外面那些巨花已经用 `dark=True` 关掉了花心，
  屋里若嫌跳，把 `CORE` 的 `emit` 降到 0.5 左右。
- **回廊的金扶手**在 `-roomb` 里偏亮（一条明显的黄带），如果嫌抢，换成 `HAND` 的 `a="gold", b="lilac_pale"` 或干脆用白。
- **花还是「板」**：这一版把瓣加宽到 0.30–0.48·size、瓣数减到 4–6，轮廓比第三轮清楚；但一朵开的还是四块板围一圈，
  远看像星芒。再往下要么给瓣加一点点弧度（三角面会涨），要么接受这是「装置」不是「花」。
- **外面那 11 朵巨花**现在读作「爪」：`bud` 的瓣近乎竖直、很长，尺寸 6–13m 时就是 5 根竖着的大板。
  这一轮按 README 的要求只保证「暗着、够不着、不穿模」，造型没动；下一轮可以把它们换成 `cup` / `lotus` 为主。
- **A 的东半南半**填了落瓣、一株大花、一张南床，密度还是比北边松（有意留的疏密差），如果还嫌空，
  可以再放一张矮床或几块碑。
