# 浅梦 · 样板 01（Shallows · mockup 01）

正式世界的**地图设计样板**。白模、只看地图设计，还没进游戏。
浅梦除了「家」（要另做、会更用心）以外的世界都在这里，一个世界一份 `layouts/<id>.json`。

**先看这张** → [`plans/_index.png`](plans/_index.png)（七个世界的地图拼在一起）
再看单个世界的 **地图**（`plans/<id>.png`，带区域名、出入口、比例尺、尺度统计）
和 **白模渲染**（`renders/<id>-*.png`：正俯视 `-plan`、俯瞰 `-bird`、出生点平视 `-eye`、各处地标）。

```
node tools/all.cjs all          # 全部：展开 JSON → 搭白模 → 画地图
node tools/all.cjs arcade       # 单个世界（也可以逗号分隔几个）
```
产物：`resolved/`（摊平后的 JSON）· `scenes/*.blend` · `glb/*.glb` · `renders/*.png` · `plans/*.png`。
格式说明见 [`SCHEMA.md`](SCHEMA.md)。工具用仓库自带的 `blender/nx.py` 搭场景，
所以 GLB 里的物体属性（`nx_*`）是齐的，将来可以直接丢进游戏。


## 浅梦的调子（这次照着做的）

- **熟悉的日常物放大到建筑的尺度**：一把椅子、一杯水、一盏灯、一张床单、一口井、一个晾衣绳。
- 颜色最柔和（16 色色板里偏紫/粉/雾白的一列，金绿蓝只做点缀）——样板里只用 `style`，
  具体色板在 `tools/build_scenes.py` 的 `STYLE` 表里，地图与白模共用同一套。
- 每个世界**一个认得出的出入口意象**，出入口都标在地图上（回家的灯 / 世界之间 / 晶体 / 跨主域 / 死胡同）。
- 走人尺度（见 `docs/blender.md`）：能自动迈上的坎 ≤0.3m，要跳的高差 ≤0.9m，门洞 ≥0.8m，
  出入口在可站立地面以上约 1.6m、四周留得下走进去的空地。

## 还没做的

- **家**（梦里的家）：要额外精心设计，没在这里做。
- 现实的家（`wake_fragment`）与总图（atlas）不在这批里。
- 网络还没定死：出入口的成对关系、跨主域的落点、晶体具体通向哪个站点，都是下一轮的事。
- 样板里的家具是**白模替身**：纸片（树、草、花、路灯）在 Blender 里渲不出来，`build_scenes.py`
  给每张纸片立了一块薄板当替身（`PROXY`），只为渲染看得见；GLB 里没有这些替身板。
