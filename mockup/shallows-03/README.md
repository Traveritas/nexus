## 下沉 · 井（`descent`）

> 一口圆井，一圈圈往下走，越往下越暗；井底却是白的、亮的。台阶一丝不苟，却没人说得清它为谁而修。头顶几只环慢慢转，院子一角一道螺旋梯升进天里。

- **第一眼**：井口的圆院里（井心以南 15.2m）朝北：一圈矮井沿，井里第一层壁龛透出暖光、往下一段段弧形的梯；头顶几只环慢慢转，天是天格（`lattice`）；隔着井，东北角一道螺旋梯盘进天里，顶上一点晶体的光；院墙外一圈高低不一的塔，几座中间断开、上半截错开浮着。
- **形状与边界**：竖井，内半径 13m、壁厚 1.2m，每 6m 一层，井底 −30m。井口在下沉的圆院里：六圈 0.3m 台阶升到半径 26m，外面一圈 6m 的墙（墙顶一圈看不见的挡板，从螺旋梯顶也跳不出去）；墙外一片齐墙顶的平地（半径 64m），塔立在上面，只看、走不到。井里每层沿井壁一圈 3m 宽的台，一段 19 级弧梯贴井壁下到下一层，下一段在 140° 之外，每层绕半圈。
- **光**：太阳仰角 80°，直落井底；暗处 8px、亮处 2px，中间几层暗而糊，井底亮而清楚。井壁越往下越深（冷紫），台面暖粉；`lamps=True`，壁龛、长洞尽头、横缝、小井漏暖光。
- **环**：头顶三只（9m、13m、14.5m，13–27m 高），井里浮着两只（7.2m 在 −8.5m，5.2m 在 −20.5m），各自倾斜慢转，不投影、不挡人。哪一层往上看都是几只环套着井口那圈天。
- **各层**：

| 层 | 有什么 |
|---|---|
| 院子（0） | 一圈圈台阶；东北角 64 级螺旋梯升到约 21m，顶上一块扇形平台和一枚晶体 |
| 一（−6m） | 五个壁龛各放一只这口井的模型，一只比一只深，底是亮的；第六个是 11m 的长洞，尽头地上一个方口，掉下去落进第二层的圆屋 |
| 二（−12m） | 圆屋（半径 5m），屋顶圆口正对上面的方口；一座井的剖面模型，第二层的台上一点金（「你在这里」） |
| 三（−18m） | 小圆屋，地上又一口盖着格栅的小井，8m 深的底上一点白，暖光往上漏 |
| 四（−24m） | 最暗；井壁上一道道发光的横缝；一座桥偏开井心 3m 横过去 |
| 井底（−30m） | 白的；三级台阶落进一汪浅水，水面映着井口：一圈暗沿围着一块亮的天 |

- **捷径**：第 2–4 层各有一块往井心伸 3.5m 的台，从上一层台边往里一迈，落 6m 正好在上面。从井沿往井心跳，直接掉进井底的水里——也就回家了。
- **出入口**：回家 `portal_home`（井底水面的天）→ `house`，`at="descent"`；晶体 `crystal_descent` 在螺旋梯顶（站点待定）；从家来落在井口院子（到达点 `house`，也是出生点）。暂不通往更深的主域。
- **待看**：阴影里只靠冷暖两组色和描边分东西，台中段和三四层偏平；塔只是方柱，螺旋梯在天格前偏细；出生点脚前井沿占了画面下面一大片白；从井底往上看，第四层的桥挡住井口一角；6m、30m 着地手感和冷启动加载没实测。网格 119 个（每段梯并成一个）。

## 浅滩 · 退潮的梯田（`shoal`）

> 一层层往下退的浅水田，湾心一汪蓝水、一座孤洲。潮五分钟涨落一回，路跟着出现、淹没。

- **第一眼**：东岸高处朝西：一层层退下去的梯田，湾心蓝水里一座孤洲（顶上晶体）；左边一根 15m 的水尺；西边海湾敞开，地平线一道亮的海天线；南北是崖。天 `ebb`（退潮）。
- **形状与边界**：海湾约 130m 宽，东北南三面崖（崖顶一圈看不见的墙），西边敞开，深水就是边。
- **分层**：岸 3.4m → T1 1.5m（永远干）→ T2 0.45m（只有高潮没过脚面）→ T3 −0.1m（齐踝）→ T4 −0.45m（齐膝）→ 湾心深水底 −2.2m。每道田坎弯法不同；每层靠下一道深色矮埂，高潮时 T2 的埂刚好露一线。
- **潮**：±0.6m、五分钟一回，进来时是低潮，150 秒高潮。水深过 0.55m 走不进去，往不更深的地方总能走，涨潮困不住人；蹚水变慢。通往孤洲的窄埂低潮、中潮能蹚过去（约一半时间），高潮被淹，埂边一路细桩标着。
- **内容**：
  - 高潮线上的圆叶：不跟潮走，一直悬在高潮的高度。低潮时从叶子底下走过，地上有影子；高潮时叶子贴着水面，从南岸一片片跳过去，到水尺脚下的方台。
  - 北边 T1 一片水洼，潮跟湾里反着走：湾里退，洼里满。
  - 水尺：15m，刻度深浅相间，顶上一点金，哪儿都看得见。
  - 闸：孤洲西边三面矮墙围着一段往深水里去的台阶。
  - 埂中途一条岔路，尽头一块空方台（死胡同）。
- **出入口**：回家——东岸地里一只杯口（白杯沿围着一汪不跟潮走的水），走进去 → `house`，`at="shoal"`；花房——东北 T2 上 `gate_vase`；沁泫池——闸里 −0.92m 那一级，只有潮最低的约 90 秒走得到（`seeping` 还不存在）；晶体在孤洲顶（站点待定）。出生点＝到达点 `house`，杯口北边约 8m。
- **待看**：中潮时埂全淹在不透明的水下，只能靠细桩认路；斜坡上实际能蹚到约 0.65m；东岸平地偏空、出生点前景一大片粉；圆叶悬在 T3、T4 上方会挡头；闸的矮墙有点像小房子。

## 花房（`glasshouse`）

> 三间歪着的玻璃房坐在一块石台上。只有屋里有阳光；玻璃外面一圈巨大的花之装置暗在影子里，看得见、走不到。

- **第一眼**：从家里的花瓶来，出生在大间东南角的花瓶前，朝西北：长花床、岛床、一株比人高的花，玻璃外一圈暗着的巨大装置。
- **形状与边界**：小连房。三间坐在石台上，两条短廊连着；石台外落下 1.2m，玻璃挡人。
  - 大间（A）13 × 8.5m，屋脊偏北。
  - 高间（B）在东，转 12°，平面是平行四边形，屋脊从 6.8m 抬到 10m；沿东墙一道楼梯上到 3.9m 的回廊，俯看另两间屋顶。
  - 低间（C）在西，六角形，下沉 0.9m：门里一块平台、三级台阶下去，当中一池浅水、一朵莲。
- **玻璃里外不一样**：28m 高处一整片只投影的顶，只在三间正上方顺着太阳开洞——屋里有阳光、格子细（2px），外面整片在影子里、暗而粗。只用现有功能（`shade`、`shadow_out`、`grid_lit`、`ghost`、`pose`），没改引擎。
- **花**：屋里塞得密，平的尖头瓣做的装置，开的、没开的、落下的；几株没开的走近会张开。
- **出入口**（来回成对）：

| 东西 | 去 | 从那边来落在 |
|---|---|---|
| A 角上方台上的花瓶，E「凑近」 | 家（`house`，`at="glasshouse"`） | 花瓶前（`house`，也是出生点） |
| B 北墙的玻璃门，走出去 | 光斑 | 门前（`sunpatch`） |
| C 里一杯水，E「一杯水」 | 浅滩 | 杯前（`shoal`） |
| C 地上一朵花的影子，走进去（投影的那株在屋外，找不到） | 长影 | 影子旁（`longshadow`） |

- **待看**：C 里花头的影子和屋顶窗棂的影子叠在一起，站着看只是一片带尖角的暗，靠地上一圈落瓣认；玻璃本身几乎看不出（虚像最浓 0.22），靠窗棂认；走近张开的花让影子图在张开时重画。

## 断梯（`stair`）

> 从一页摊开的纸上起来的一座楼梯，断成一截一截，绕着中心盘三圈往上；掉下去就回家。

- **第一眼**：站在一大页摊开的纸上（白底横纹，中间一道书沟），面前一跑楼梯往上；正中一根线从头顶垂下，吊着一枚慢慢起伏、转的大锤；远处雾里浮着几截斜的、倒的断梯。天 `plumb`（种子 3）。
- **形状与边界**：三圈方形螺旋，0 → 33m，约 18m 见方，18 个断口。头一圈断口都在纸上方，没跳过去落回纸上；往上断口里侧落在下一圈上，外侧是虚空。
- **路线**：
  - 第一圈：一跑；1.7m 平跳；侧躺的一跑（踩着平的侧面走，锯齿在一边）；三块浮着的方石（每块高 0.5m）；转角头顶倒挂一跑，从底下钻过去；1.5m 平跳。
  - 第二圈：五块方石（每块高 0.45m）；一跑后 1.9m 平跳；转角旁从头顶底面垂下一串慢慢荡的踏步（够不着，只是看）；6m 宽的歇脚平台。
  - 藏着的角：歇脚平台外侧四块方石伸出去，尽头斜板上浮着晶体 `crystal_stair`（站点待定）。
  - 第三圈：长的一跑中间断开 2.4m，要按 Shift 快走着跳；最后一跑的踏步越往上越薄、越稀，最后一级发亮。
  - 头顶：44m 高一块 34m 见方的底面，正对最后一级开着方洞，大锤从它上面吊下来。
- **出入口**：从家来——到达点 `house`（＝出生点）；去高处——最后一级上方 `portal_heights`，高处还没有，暂指 `isles`（云阶）；回家——掉到 −14m 以下进 `house`（`fall_at="stair"`，引擎新功能「掉进别处」）。
- **实测**：用真实按键把 18 个断口各跳一遍都过得去；掉下去到 `house`；走上最后一级到 `isles`；60fps；zfight 0。
- **待看**（要精修，2026-10-14 用户说先保留）：2.4m 那跳要 Shift，不知道的人会卡住；头顶底面从第三圈看偏重（再浅就融进雾里）；方洞里只有天；回家只有掉下去一种。
