# 浅梦 · 样板 02（Shallows · mockup 02）

浅梦第二轮：先把阵容重新排一遍（2026-10-14），再挑两个新世界直接做成**能在网页里走的原型**（不是白模）。
第一轮样板见 [`shallows-01/`](../shallows-01/README.md)，家见 [`docs/home.md`](../../docs/home.md)。

## 为什么重排

1. **七个世界是同一招**：都是「日常物放大到建筑」，一把椅子、一张桌、一口井、一张床单……单看都成立，连着走就是一个套路七遍。
   其中几样本来就是不要的套路（孤零零的椅子、晾衣绳、巨大的桌面、路灯）。
2. **尺度和形状都一样**：都是「家的 4~6 倍、箱庭 · 一片」，从平面图出发、对称、有轴线（[worlds.md](../../docs/worlds.md) 里批评过的那种）。

家做成了以后（紧的屋里 ＋ 门外循环的原野），浅梦别的世界在大小和形状上要拉开；
新加的世界从光、时间、影子这些**地方自己的性质起意**，不靠放大的日常物；但一个机制撑不起一个世界——还要有东西可看、有路可走、有地方可去。
形状多从有边的（封闭、围起来、迷宫）或塞得满的想起，无边循环只在想法需要时用（见 [worlds.md](../../docs/worlds.md)）。

## 光斑 · 光的迷宫（`?world=sunpatch`，第二版）

> 一座昏暗的迷宫，头顶几扇看不见的天窗漏下几块光，慢慢地在巷子里移动。光里格子细、记号显出来；暗处看得见墙和路，但粗、糊。

- **第一眼**：西边一条通向中厅的路上，站在一大块暖光里朝东；地上几个只在光里显出来的记号，前方巷子半亮半暗；抬头几扇悬在半空、发白的天窗。
- **形状与边界**：迷宫，72 × 72m（12 × 12 格，每格 6m，路宽约 5m）。墙 3m 高、0.9m 厚，顶面浅一些；四周 4.6m 的外墙围住。迷宫随机生成后打掉一成多的墙绕出环路，死胡同不多。
- **光**：头顶 34m 一整片看不见的顶开 9 扇天窗（带十字棂的方窗、两条长缝）；太阳仰角 72°、十二分钟转一圈，每块光斑绕自己天窗的正下方转（半径约 11m），光总在差不多的区域，任何时刻约两三成的地是亮的。暗处不全黑（`umbra` 的影子留一点受光），格子 8px；光里 2px。
- **光里才显出来的**：岔路口地上的记号＋箭头（金色窗形 → 回家、粉色花形 → 花房、淡蓝菱形 → 晶体）；墙两面的小方块纹样带；中厅地上一圈 48 格的刻度，中间那扇天窗的光斑沿着它走，像一只钟；软垫园里的低矮软垫。
- **几处角落**：中厅（24 × 24m，中间一座矮圆台）；西北观景台（15 级台阶上到 4.5m，看得见整座迷宫哪几条巷子亮着）；东北浮着的六块斜板，光扫过时影子在地上转；东南软垫园。
- **出入口**：
  - 回家（东北角）：地上一块发光的落地窗形（1.8 × 2.6m、十字棂，暗处也看得见），对应家里客厅的落地窗；走进去回家。
  - 花房（西南角）：方台上一只插花的大瓶，E「凑近」。
  - 晶体（东南角，站点待定）。
- **明暗**：暗处压暗到干净的深紫。试过半影（光斑边上的平滑渐变）和每帧连续转的太阳，帧率掉得厉害，撤回了：影子是硬边，太阳每 0.25 秒走一步。
- **待看**：天窗有点像吊顶的灯板（可以换暖色或再抬高）；记号只在光扫到时显形，认路要等光；浮板、软垫园有时长时间照不到。

## 长影 · 影子的盆地（`?world=longshadow`，第二版）

> 一个被缓坡围住的盆地，太阳压在西边的山脊上不动。盆里一处挨一处都是影子：桌椅、秋千、花瓶、窗框、树林、竖琴……投下影子的东西都看不见、碰不到。

- **第一眼**：盆地东边朝西，太阳贴着西边山脊；脚前一张长桌和一圈椅子的影子，后面是悬空窗框的田字格影子，左边几道长影伸过来，右手边的北坡背着光。
- **形状与边界**：盆底半径 50m，浅碗形（远处的地朝人抬起来，影子不全压成线）；50–80m 是缓坡，坡顶高 8–24m，西边最矮；半径 68m 处一圈看不见的墙。太阳仰角 12°，从西偏北来，不动；西边的山脊把盆地约三分之一罩在影子里。
- **影子景象**：长桌和一圈椅子；慢慢荡的秋千（影子来回伸缩）；一只瓶口外翻的大花瓶；悬空的田字窗框；一片稀疏的树林（走进去光是一块块的）；一座格栅棚（地上一片格子光，正中浮着一枚晶体）；一架竖琴（弦的影子是一根根虚线）；顶上挂着圆盘、慢慢转的转杆；铺到东坡上的锯齿楼梯影子；一只衣柜。
- **出入口**（都在地上的影子 / 亮格里，走进去）：
  - 回家：衣柜影子中间那一线光（两扇柜门之间的缝）→ 家（进来时是从衣柜）。
  - 花房：花瓶影子的瓶口尖。
  - 光斑：窗框影子下排左边那块亮格。
  - 晶体：格栅棚格子光的正中（站点待定）。
- **虚像**：每件投影的东西都有一层淡淡的虚像——34m 外最浓（约四成），14m 内散掉，只剩影子；远远看得见桌椅、树林、竖琴、衣柜，走过去就没了。山脊上另有三样只有虚像、没有影子的：北边一扇很高的门框、南边一段伸进天里的楼梯、东北一座细塔，走到坡上就散。
- **待看**：传送点没有可见标记，全靠影子形状认（衣柜那一线光只有 0.4m 宽）；北坡、西北坡背光，整片偏闷；会动的影子让影子图每帧重画（4096²），真机帧率要看。

## 引擎里为这两个加的（通用的，别的世界也能用）

| 功能 | 写法 | 说明 |
|---|---|---|
| 只投影的东西 | `nx.shade(obj)`（`nx_mat=shade`） | 看不见、不挡人，只往太阳的影子图里画 |
| 只在光里的东西 | `nx.matte(..., lit_only=True)`（`nx_lit_only=1`） | 在影子里的纹素不画；自己不投影 |
| 影子图外面算暗 | `atmosphere(shadow_out=True)` | 影子图只盖着人周围一圈，外面默认是亮的；暗的世界要反过来 |
| 影子图盖多远 | `atmosphere(shadow_reach=米)` | 默认 40m；太阳低、影子长的世界要大 |
| 太阳转 | `atmosphere(sun_turn=度每分)` | 太阳绕竖轴转，影子跟着走（`?suntime=秒` 或 `__nexus.sunTime(秒)` 拨到某一刻） |
| 亮处格子细 | `atmosphere(grid_lit=级)` | 一块 8×8 的平均亮度够亮，就用这一级（如 1 ＝ 2px），暗处照 `grid` |
| 影子多暗 | 天空主题的 `shade` | `[影子里的受光档, 压多少]`，默认 `[0.22, 0.85]` |
| 低太阳照亮平地 | 天空主题的 `lift` | 受光按「朝向 · 太阳」÷ lift 算 |
| 半影 | `atmosphere(penumbra=米)` | 影子边上软的一圈，明暗之间是渐变 |
| 虚像 | `nx.matte(..., ghost=(最浓, 近, 远))` | 远处半透、走近散掉 |
| 会动的影子 | shade 物体也认 `nx_spin` / `nx_bob` / `nx_sway` | `nx_sway`：绕本地 x 来回荡（秋千），`nx.behave(obj, sway=度)` |
