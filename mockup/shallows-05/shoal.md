# 浅滩 · 头顶的水（`shoal`）

> 人走在一片干的海底上，水面是头顶一整块平的天花板。抬头看见倒过来的海底，只是倒影里多出几样地上没有的东西。

`blender/scenes/shoal.py` 整个重写（第三版）。上一版（1m 网格的噪声地形、按高度分色带、整片地形逐面翻上去的倒影）作废。
这一版只用大块面：平的海底、缓坡的沟、沿可走区域的边拉起来的几排斜墙、几块圆润的石头。截图在 `.shots/shoal-*.png`。

## 一句话

一片干的海底，水在头顶：地升进水里的地方就是墙，整片是一个顶是水的洞穴迷宫。抬头是一层慢慢流动的蓝水面，隔着它是倒过来的洞穴，
倒影里多出一座塔、一跑楼梯、一圈柱子、一扇门；正上方一处圆窗透出天和一朵云，站进窗下那圈光里就回家。
东边一根石柱穿过水面，楼梯绕着它盘上去，头钻出水面是一片潟湖。

## 第一眼

出生在**起厅**（−4, 38.5，地板 −9m，头顶 9m 是水面），朝南偏西：

- 左前方是**圆窗落下的那圈光**：地上一个白的圆，一柱很淡的光从头顶的白环直落下来；
- 脚下和前方是一道道**沙纹**（低矮的长棱，微微弯）；
- 正前方一条 10m 宽的**宽沟**往南沉下去，两边是一块块斜着往外倾的岩壁；沟的尽头、头顶的倒影里**倒挂着一座粉色的塔**；
- 头顶是蓝的水面，上面映着倒过来的岩壁（紫的剪影），几片浮叶的影子贴在水面上。

## 形状与边界

- **形状**：围起来的一片 ＋ 迷宫。七个厅（起厅、塔厅、东厅、西厅、北厅、深沟尽头、楼梯间）用沟连着；东南一团低矮的窄道
  （环路 ＋ 两条死胡同），厅里立着几根从地上一直穿进水面的石柱。
- **地**：每个厅是平的，沟是直的缓坡（最陡约 24°），没有噪声。厅里铺几何的沙纹（每个厅一个方向）：
  每一截是**封闭的矮实体**（截面是个矮三角，底压在地下 2cm，两头收成一个点），只铺在厅里**完全平**的那片地上，
  离墙和石柱 1.4m、离石头 1m，圆窗、塔下的沙纹圈、黑坑、出生点周围不铺（65 截）。
  - 厅：净空 6.5–13.5m（北厅 7、西厅 6.5、东厅 7、起厅 9、塔厅 11、深沟尽头 13.5）；
  - 东南的窄道：地板 −2.8m，**净空 2.8m**，宽约 3.8m；
  - 最深：深沟尽头 −13.5m。
- **墙**：沿可走区域的轮廓（化简成 4.5m 一段的折线）拉起来的五排顶点：脚下近乎直立，往上往外倾 2–5m（厅里倾得多、窄道里少），
  中间一排进进出出，所以是一块块的面；顶边没在水面下 6cm，再往外平伸一圈「礁」。两条通道之间的岩体薄的地方，倾斜按岩体的厚度收住，不互相穿。
- **边界**：墙就是边（实体碰撞，没有看不见的挡板）。潟湖那一层用岛的边挡（一圈看不见的挡板，岛、石堤、出水的楼梯以外走不进水里）。
- **大小**：洞穴约 95 × 115m（x −44…60，y −56…66）；潟湖在东边 x 47…88。
- **光**：太阳斜着从东南上方来（仰角约 50°），墙有明暗两面；圆窗下那一圈是自发光的白。
- **水波光斑**（引擎新功能 `atmosphere(caustics=…)`）：水面以下、照得到太阳的地和墙上，一层慢慢流动的冷白亮网纹，
  沿太阳方向从水面投下来；越深线越细（窄道里粗，塔厅里细），影子里没有。

## 内容

| 区 | 有什么 |
|---|---|
| 起厅 | 圆窗、光柱、地上的光圈；几块石头（其中一块**倒影里没有**）；沙纹；三条路出去（宽沟、东、西）＋ 一条坡到北厅 |
| 宽沟 → 塔厅 | 一路往下；塔厅里三根穿进水面的石柱、几块石头；头顶倒挂的塔；塔的正下方地上三圈沙纹、一枚晶体；水面上浮着一只船的底 |
| 深沟 | 从塔厅再往下，越走越窄越暗；尽头一个黑的圆坑、一圈矮沿（沁泫池的位置，还没通） |
| 东南窄道 | 塔厅一条长坡升上来，绕成一个环、两条死胡同，另一头坡下东厅；净空 2.8m，头顶的水最近 |
| 东厅 | 头顶倒影里一跑断在半空的楼梯（只在倒影里） |
| 西厅 | 头顶倒影里一圈七根柱子；水面上一片大叶子，底下垂着根 |
| 北厅 | 空的一片；倒影里一扇门框 |
| 岩脊下的沟 → 楼梯间 | 沟从一块骑在上面的岩底下穿过（这一段头顶是石头，不是水）；楼梯间是一间圆室，正中一根石柱穿过水面、再往上立成一根尖；28 级扇形踏步绕柱一圈 |
| 潟湖（第二层） | 楼梯顶上一座岛，石堤连到另外四座（一条岔路），最远那座上是花瓶；几块露出水的礁；西边一道岩脊（两段 ＋ 中间一块）把核心挡住 |

**倒影的做法**：核心那一片（x < 37）的地、墙、石头沿水面翻上去一份，颜色压在蓝一列（地）和紫一列（墙），不投影、不挡人；
水面是两层（朝下 z=0、朝上 z=0.01）的半透（ghost 0.45 / 0.62）纹样「流」，倒影隔着它看。
倒影里多出来的四样东西用粉一列，好认。圆窗那里水面开一个干净的圆洞（44 段），倒影的地在窗的正上方挖一个半径 10m 的圆，透出天（`ebb`），
正头顶放了一朵云（`sky_sprite`），从窗里抬头能看见。潟湖底下的水不翻倒影（从下面看是透的），岩脊挡住从潟湖看向核心倒影的视线。

## 实测（2026-10-16）

- 沙纹逐截检查（Blender 里另写的脚本）：65 截，**非流形边 0**（全部封闭）；每个顶点往下打到地面，底下的点都正好在地下 2cm、上面的点离地不超过 0.14m（**没有悬空**）；和地以外的所有网格**相交 0**。
- 引擎改动后，家、光斑、下沉的出生点截图和改动前**逐像素一样**（0% 不同）。
- 第二轮（沙纹＋光斑）之后重跑：zfight 0（81 个网格）；实走 53/53；travel 37/45，失败的都在预期内（`shoal → seeping`、各处「到达点 xxx 在 house 里」、`去不了 home/descent`、日记「去过」）。

- `node scripts/blender.cjs zfight shoal` → **0 对共面**（81 个网格）；`clip shoal` → 0 处。
- 实走：`DIST=dist-shoal node scripts/_walk_shoal.cjs`（路线按新地图重写）→ **53/53 通过**：出生点 → 宽沟 → 塔厅（晶体前）→ 深沟尽头（黑坑前）→ 回塔厅
  → 长坡 → 东南窄道一圈 → 坡下东厅 → 岩脊下的沟 → 楼梯间 → 绕柱九段上楼 → 出水的岛 → 石堤 → 四座岛（含岔路、花瓶岛）→ 回来 → 九段下楼；
  另外：走进圆窗下的光 → `house` ✓；花瓶 E「凑近」→ `glasshouse` ✓。另测了从四座岛往水里走都被岛边拦住。
- `travel.cjs`（指向 `dist-shoal`）→ 48/57；浅滩相关的失败只有预期内的：`shoal → seeping`（世界不存在）、`到达点 shoal 在 house 里`（家里还没放传送物）。
  `shoal → house` ✓、`shoal → glasshouse` ✓、`glasshouse → shoal` ✓（落在花瓶前）。

## 待看（诚实说）

- **水波光斑**：浅的地方（东南窄道，离水面 2.8m）地本来就亮，光斑的线又粗，有时连成一大片白；起厅的网纹偏密。可以调 `size` / `strength`。
  光斑只算太阳和影子，不知道上面浮着的叶子、船——它们的影子里照样没有光斑（对的），但圆窗下也照样有（地是白的，看不出来）。
- 远看头顶仍有点像蓝天上挂着紫的岩块；地上有了光斑以后，「在水底」好认多了。
- **倒影上有一层粉的抖点**：紫的倒影和蓝的水面半透叠在一起，落色板时混出粉点，近看有点脏。
- **倒影里多出来的楼梯和门不好认**（倒挂、粉色、只有几块），塔和柱子认得出来。四样里只有塔的正下方是出入口。
- **潟湖偏白、偏空**：雾（`ebb`）把远处洗得很淡；水面从上面看是一片淡紫蓝，透下去看不太到下面的洞。岛的形状比较老实。
- 从潟湖往西看，岩脊上方偶尔露出一点核心倒影的尖（很小）。
- 楼梯间里那座出水的岛悬在水面上（从楼梯间往上看是一块浮着的石头底）。
- 墙的轮廓来自 1m 格子的可走区域再化简，个别地方还看得出折线的规整。
- 帧率没测（网格 81 个，地、墙、倒影各是一个大网格）。
