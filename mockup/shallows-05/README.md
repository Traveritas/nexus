## 接进网里（2026-10-16）

- 现实的床「睡」→ `house` 床边（到达点 `wake`）。旧的 `home`、`procession`、`room` 是 legacy：还在、`?world=` 进得去，但不在星图上（`src/worlds.ts` 的 `LEGACY`）。

## 传送点重做（2026-10-16）

没有记号、走进去就传送的几处，改成落在一样看得见、要动一下的东西上（门、掉下去不在此列）：

| 在哪 | 去哪 | 现在 |
|---|---|---|
| 光斑 · 地上那扇光的落地窗 | 家 | 两扇窗扇是光做的，盖着地上一个洞；E「推开窗」往下翻开，走上去掉下去，落在客厅落地窗前 |
| 长影 · 花瓶的影子 | 花房 | 瓶颈的影子里插着一丛真的花，只在影子里看得见（`lit_only="shade"`），伸出瓶的轮廓就断；E「凑近」 |
| 长影 · 窗框的影子 | 光斑 | 左下那格关着一扇看不见的窗扇，影子是暗的；E「推开窗」亮出来，走进去 |
| 长影 · 衣柜 | 家 | 柜子看不见，柜里一排衣服只在影子里看得见（悬在半空围出一只柜子），柜门上两只实的把手；走到柜前 E「打开柜门」，门影张开、柜影中间透出一线光，从两扇门中间走进柜里（同家里那只） |
| 花房 · 星形花影 | 长影 | 影子往花头那边的半空停着一串瓣（只在影子里看得见）；E「接住」 |
| 浅滩 · 圆窗下 | 家 | 那圈光正中立着一只到膝盖高的杯子（同家里那杯的样子，水浮在上半截；花房去浅滩那只也是这么大）；E「一杯水」（光柱留着，只是看的；之前试过亮沿垂下一根水，像根杆子，换掉了） |

模型：家里边几上的花瓶、去花房的大瓶（光斑、浅滩的岛、花房回家那只）改用 `fu.flower_vase`——瓶直接立着，不垫方台；
一杯水改用 `fu.water_glass`——半透的薄壁玻璃、厚底、一圈实的杯沿，水浮在杯子上半截、杯底空着（浅滩「水在头顶」的小样），家里茶几上那杯和花房那只齐腰的同一个样。
