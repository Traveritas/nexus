## 0. 项目背景（一段话）

NEXUS 是一个网页上的 3D 梦境游戏，像 Yume Nikki（梦日记）、Project Somnia、ENA: Dream BBQ 那样：很多形状、气质各不相同的「世界」，靠传送物连在一起，可以闲逛、迷路、撞见东西。
画面是低模、像素化、落到 16 色色板上（格子粗细随明暗变）。
场景用 Blender 的 Python 脚本从零搭（`blender/scenes/<世界>.py`，调用 `blender/nx.py` 的 `nx.*` 函数），导出 GLB 给网页（`src/`，three.js）用。
浅梦（Shallows）是最柔和的一个主域，家（`house`）是它的中枢。

## 2. 用户的口味（一定要守）

- **干净的低模**，颜色用色板里低饱和的那些（雾白、淡紫、粉、雾蓝，金只做点缀）。做不好的模型（人、动物、复杂的写实物件）就别做。
- **避开套路**：路灯、孤零零的椅子、晾衣绳、放大成建筑的日常物（巨大的桌子、杯子）、老小区、公交站，这类「梦游戏、怀旧」的现成意象都不要。奇怪的感觉要从这个地方自己的性质来：光、尺度、天空、地面、结构本身。
- **一个机制撑不起一个世界**：要有东西可看、有路可走、有地方可去。空旷只有在它就是这个世界的意思时才行，不能是没做完。
- **形状**：从有边界的或塞得满的形状想起（封闭、围起来、迷宫）。不要默认做成无边循环的平地。
- **宽敞**：通道别太窄，人走着不挤。
- **回家**：用这个世界自己的一样东西，不用家的大门。
- **不对称**：别处处对称、别从平面图出发画成建筑图纸。

## 4. 工具和命令

```
node scripts/blender.cjs build shoal          # 跑场景脚本 → blender/shoal.blend + public/scenes/shoal.glb
node scripts/blender.cjs zfight shoal         # 共面检查（会闪的面），要 0
node scripts/blender.cjs clip shoal           # 穿模检查（只查家具类构件，不全面）
npx vite build --outDir dist-shoal            # 构建网页（各用各的目录，别用 dist）
DIST=dist-shoal node scripts/view.cjs shoal 名字:x,y,z,朝向[,俯仰]   # 截图到 .shots/shoal-名字.png
```

- `view.cjs` 的坐标是 Blender 的（脚底位置，Z 朝上），朝向和 `nx.spawn` 一样（度，0 朝 +Y，90 朝 −X），俯仰为正是抬头。可以一次给多个机位。
- 用真实按键走路，参考 `scripts/walk.cjs`（puppeteer + `window.__nexus` 调试接口：`__nexus.state()`、`__nexus.keys(code, down)`、`__nexus.go(world)`）。断梯以前有一个逐个断口自动跳的脚本，归档在 `archive/shallows-04-var/scripts/walk-stair.cjs`，可以改了再用（路线表要按新路线重写）。
- 传送物总检查：`npx vite build && node scripts/travel.cjs`。注意：家里的传送物还没放，「到达点 xxx 在 house 里」这类失败是预期的。
- 用户如果开着 `npm run dev`，新生成的 `.glb` 它认不到，要重启才行（不然会报 `Unexpected token '<'`）。汇报里提醒一句。

## 5. 任务 A：浅滩重做——「头顶的水」

（`blender/scenes/shoal.py` 整个重写。上一版的梯田、潮汐都作废，别沿用。）

### 想法

借一个真实的光学现象：人在水下往上看，水面除了正上方一圈，其余部分都像一面镜子，映出的是水底。

- 人走在一片**干的海底**上，**水面是头顶一整块平的天花板**（固定高度，不会动、不碰撞）。
- **抬头看到的是倒过来的海底**：就是你脚下这片地的倒影。
- **倒影和实际对不上**：倒影里多出一些东西，比如一座楼梯、一扇门、一棵树、一圈柱子，可地上没有。走到倒影里那样东西的正下方，它就是一个出入口（传送物放在地上对应的位置，地上可以有一点轻微的记号，比如沙纹在那里绕成一圈）。
- **正上方的圆窗**：只有一处，头顶是一圈透亮的圆（水面在那里不反光），能看见水面上的天。站进那圈光下面就回家，接上「从一杯水进来」。

### 不让它单调：靠地形和水面的关系

- **水面是平的，地是起伏的。地隆起、碰到水面的地方就是墙**。整片区域因此变成一个顶是水的洞穴迷宫：
  - 地离水面很近的地方是低矮的窄道（头顶净空 2.2–2.8m 左右，但别低于 2.1m）；
  - 沟里水面高高在上，是暗而宽的大厅（净空 8–15m）；
  - 外边界就是地一路升进水里。
- **几处台阶或坡通出水面**：头钻出去是第二层。这一层是一片平的水面（站不上去，用看不见的挡板或岛的边拦住），零星几座小岛，从上往下能透过水看见下面的迷宫。去花房的花瓶放在其中一座岛上。
- **从下面看水面上的东西**：浮叶的背面、垂下来的根、一只船的底，够不着。用 `nx.shade` 给它们投影到地上。
- **地面**：海底那种沙纹，一道道的；暗沟深处颜色最深。通往沁泫池的门就在最深的那条沟里。
- 疏密要有变化：密的一团、空的一片、再密一团。从出生点就要看得见一个让人想走过去的东西（比如远处大厅里倒影中的一座塔）。

### 做法提示（都用现有功能）

- **水面**：一块平面。从下面也要看得见，所以做成很薄的盒子，或上下两面各一片（别共面，错开几毫米）。不挡人（`collide=False`）、不投影。纹样可以用 `flow`（水面），颜色压在雾蓝一列。
- **倒影**：在 Blender 里把海底（地形、岩、要倒映的东西）沿水面高度 H 翻上去复制一份（z → 2H − z，翻完重算法线），用 `ghost`（虚像）画淡，`collide=False`、`shadow=False`。倒影里「多出来」的东西只放在倒影那一份里。
  - 要确认在像素化以后，倒影还认得出来、不糊成一片；试几组 `ghost` 的最浓、近、远。
  - 倒影在水面之上，所以水面本身要半透（也可以用 `ghost`），或者干脆不画水面只画倒影。哪种好看用截图决定。
- **圆窗**：水面在那一圈开一个洞（或那里不画水面，也不画倒影），透出天。天空主题自己挑，可以用 `ebb`（退潮，雾偏冷、西边一道亮的海天线），也可以用别的，在 `docs/sky.md` 里找。
- **光**：太阳从上面照下来，经过水面，地上应该偏暗偏冷；圆窗下面是一块亮的。暗处格子粗、亮处格子细的设置（`grid_lit`）可以用来把圆窗下的那块变清楚。
- 大小：迷宫部分大约 80–120m 见方就够了，别做得太大太空。

### 出入口（来回成对，落点名就是对方世界的 id）

| 东西 | 去 | 写法 |
|---|---|---|
| 圆窗下那圈光，走进去 | 家 | `nx.portal(..., "house", at="shoal", mode="walk")`；到达点 `nx.arrive("house", …)`（从家来落在这里，也就是出生点附近） |
| 岛上的花瓶，E「凑近」 | 花房 | `pf.gate_vase("shoal", 位置, 朝向)`（`blender/prefabs.py`，它会自己放传送物和到达点 `glasshouse`）。花房那边的「一杯水」会落到这里，已经对好 |
| 最深的沟底 | 沁泫池 | `nx.portal(..., "seeping", at="shoal", mode="walk")`。`seeping` 还不存在，先占着 |
| 倒影里多出来的东西正下方 | 自己定，可以是晶体 | 晶体 `nx.entrance(...)`，站点地址先空着，写 `"#"` 或照别的世界的写法 |

入口不要放在需要跳才够得到的地方。

## 6. 任务 B：断梯美化——炸开的、穿过自己的、越来越大的楼梯

（在 `blender/scenes/stair.py` 上改：保留世界 id、出生点、到达点 `house`、掉下去回家的 `fall_to`、顶上去高处的出口、晶体。）

现在的问题：纯浮空的方石跳台没有来由、不好看，整体太老实。用户要更超现实、更有错乱感。用下面三个想法叠在一起：

1. **炸开的楼梯（底子）**：整座楼梯像爆炸图那样拆散。踏步、扶手、栏杆、休息平台、转角柱、梯梁，各自离原位偏开一点，浮在附近。跳的平台就是楼梯自己的零件（一截踏步、一块休息平台、一根倒下的梯梁），不再是方石。远看要看得出它原本是一座完整的楼梯（零件按原来的位置排，只是散开）。
2. **楼梯穿过自己（错乱）**：用**缝**（`nx.seam`）。走上一跑楼梯、转过休息平台，人已经在另一处；刚才那跑出现在头顶或者脚下。往上爬了几圈，回头看出发的那页纸，它在你上面。
   - **注意**：缝只能接**两个不同的世界**（`src/seam.ts`；家的大门就是 `house` ↔ `house_out`）。所以要把断梯拆成两个世界，比如 `stair` 和新建的 `stair_b`（中文名写进 `src/worlds.ts` 的 `WORLD_NAMES`，这是唯一允许碰的 src 文件），两边各放一道缝、`to` 互相写对方，门洞两边的东西要一模一样地对上（看 `docs/blender.md` 里 `seam` 那一条的说明）。缝要放在一个框里（休息平台上的一道门框、一截拱、两根柱之间），宽 ≥ 0.8m、高 ≥ 1.9m，背后放一块看不见的挡板（照 `house_out.py` 的 `door_back_block`）。
   - 至少做一处让人明显感到「不可能」的地方，比如透过缝看见的那一截，其实就是你刚走过的地方，只是换了一个角度。
3. **尺度错乱**：越往上踏步越大，最后几级每级比人还高（要跳上去，每级高差 ≤ 0.9m，否则上不去）。旁边并排浮着一座迷你楼梯，只到脚踝，一直通到很远。站在大踏步上往下看，刚走过的那一跑缩得像模型。

### 要守住的

- **难度温和**：不要再出现必须按 Shift 才跳得过去的断口。平跳 ≤ 1.8m，往上跳 ≤ 0.9m（行走尺度见 docs/blender.md）。头一圈的断口下面要有东西接着（落回纸面），往上才可以是虚空。
- 掉下去照旧回家（`atmosphere(..., fall_to="house", fall_at="stair", fall_y=-14.0)`）；新世界 `stair_b` 也要写同样的 `fall_to`。
- 顶上去高处：照旧 `portal_heights` 指 `isles` 占位。
- 正中现在有一枚吊着的大锤，和下沉撞过意象，**去掉**，不要任何从天上吊下来的东西。中心换成别的焦点，或者干脆让炸开的楼梯本身就是焦点。
- 每个断口都要用真实按键实测能过。
