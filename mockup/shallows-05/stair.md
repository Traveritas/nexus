# 断梯 · 炸开的、穿过自己的、越来越大的楼梯（`stair` / `stair_b`）

第三批（[handoff](handoff.md) 任务 B）。底本是第三轮的 `blender/scenes/stair.py`（浮空方石那版），
这一版把它**拆成两个世界**重做：`stair`（下半，纸上那半）与 `stair_b`（断梯 · 那边，上半，越往上越大那半），
中间靠一道**缝**接上。第四轮的 `stair-var-1/2` 归档在 [`archive/shallows-04-var/`](../../archive/shallows-04-var/)，
里面的「碎段当跳台」的做法借了过来。

- 建：`node scripts/blender.cjs build stair`（`stair_b` 同）；检查：`zfight` / `clip stair`、`zfight / clip stair_b`
- 网页：`npx vite build --outDir dist-stair` 后 `?world=stair` / `?world=stair_b`
- 走测：`DIST=dist-stair node scripts/walk-stair.cjs stair`（`stair_b` 同，另加 `SEAM=1` / `FALL=1` / `TOP=1`）
- 截图：`.shots/stair-*.png`、`.shots/stair_b-*.png`
- 中文名：`stair_b` 加进 `src/worlds.ts` 的 `WORLD_NAMES`（`断梯 · 那边`），没动 `CONSTELLATION`（不在星座里，自动排外圈）

## 一句话

一座被炸开的螺旋楼梯，从一页摊开的纸上起来，绕着中心盘两圈往上；半路穿过一道缝，人已经在另一座里，
回头能看见自己刚爬过的那一跑挂在下面；越往上踏步越大，最后几级要跳上去，旁边并排浮着一座只到脚踝的迷你楼梯。

## 第一眼

出生在摊开的纸上（白页、中间一道书沟），面朝楼梯（东偏南）。眼前是**一圈深紫的踏步**一级级往左上盘，
**扶手与梯梁各自偏开、浮在旁边**（扶手是一道很黑的细杆，断成几截），再远一点是**正中那根被炸开的柱心**
（一摞错开、转开的圆板，从纸上立到 42m 高的雾里，替掉了原来吊着的大锤），四周浮着碎踏步，
头顶 `halo`（天环）五道细环慢慢转，雾里另有九截斜的、倒的断梯。近处能看出这是一座楼梯，远看是「一摞散开的楼梯」。

## 形状与边界

- **形状**：路 ＋ 竖向。两个世界各是一圈**螺旋**（不是方螺旋——方螺旋的转角平台每转一次把路往外推半格，
  两圈就散到 30m 外去了，改成绕圆心的螺旋，半径基本不变，上下两半才对得齐）。
- `stair`（下半）：纸（22 × 20.6m）＋ 绕 (0,0)、半径 5.6m 的螺旋，38 级（每级高 0.30、进深 0.80、宽 2.7），
  升到 **z = 11.4**，跨约 **0.86 圈**。三处断口都在纸上方（掉回去落在纸上）。
- **门**：螺旋尽头把 16° 的弧换成一块**直的弦平台**（宽 5.2m），门洞在这块平台正中，
  `(-3.64, -4.19, 11.40)`，朝 **−131°**（沿着路继续走的方向）。门洞名义 1.34 × 2.30m，门框净口 / 缝都取
  1.32 × 2.29m（`DOOR_W−0.02` / `DOOR_H−0.01`，同家里的大门写法），门后 0.45m 一块看不见的挡板（照 `house_out.py` 的 `door_back_block`）。
- `stair_b`（上半）：从同一道门的另一边接着，螺旋再往上 40 级，分四段、**踏步越来越大**
  （高 0.30 → 0.42 → 0.55 → 0.70，宽 2.7 → 3.2 → 3.8 → 4.6），升到 **z = 29.0**，
  跨约 1.0 圈（半径 5.6 → 7.6，慢慢往外飘）。再往上是一块休息平台 ＋ 六个**巨踏步**（每级高 0.82、比人还高）到 **z = 34.2**。
- **边界**：纸以外、以及所有浮着的东西以外都是虚空，掉到 −14m 就回家（`atmosphere` 的 `fall_to`）。
  上半越往上越往外，最后那几块巨踏步已经出了纸的范围，脚下就是虚空。
- **尺寸**：主楼梯约 12–15m 见方；迷你楼梯盘到半径 16.5m；远处雾里那九截断梯在 55–115m。

## 缝（这一版最要紧、也最容易看错的地方）

- 缝只能接**两个不同的世界**，所以把断梯拆成 `stair` / `stair_b`。两道缝贴在一起、`to` 互相写对方，
  门框、门槛、门前那块弦平台由 `door_common()` 在两个世界**各搭一份一模一样的**，所以走过门槛不转场。
- 门洞两边的东西要对上：弦平台是同一个函数、同一组坐标；门框是同一个 `pf.frame`。
- 挡板（`door_back`）按**这道缝的朝向**放（离缝 0.45m）——第一版按门的 yaw 放，结果在 `stair_b` 里
  挡板落在了人和门之间，人走不到门口（走测里「走缝」那一项走到 `isles` 去了，查出来是这个）。
- **不可能的一处**：门在螺旋顶上，门后的路是往下走的。所以在 `stair_b` 里
  **站在门口抬头**，能看见自己马上要爬的那一跑**从门洞上方横过去**；**回头往下看**，
  透过门洞看见的是刚爬过的那一跑（换了一个角度、从外面看）。门洞被楼梯穿过去、上面下面都是楼梯。
  `stair_b-back.png` / `stair_b-up.png` 是这两张。

## 实测

| 项 | 结果 |
|---|---|
| `zfight stair` | **0**（86 个网格，0 对共面） |
| `zfight stair_b` | **0**（40 个网格，0 对共面） |
| `clip stair` / `clip stair_b` | 0（这两个世界没有 `nx_piece` 家具，检查范围为空） |
| 断口（真实按键） | `stair` **3/3**、`stair_b` **13/13**，**全部慢走**（不用 Shift） |
| 走缝 | `stair → stair_b` ok；`stair_b → stair` ok |
| 掉下去回家 | `stair → house` ok；`stair_b → house` ok |
| 走上最后一级 | `stair_b → isles` ok |
| `travel.cjs` | **37/45**；没过的是：`去不了 home` / `去不了 descent`（旧中枢那两个，与断梯无关）、四处 `到达点 xxx 在 house 里`（家里还没放传送物，预期）、`shoal → seeping`（世界不存在，预期）、日记「去过」清单。断梯自己的：`stair_b → isles` **ok**（`stair` 这一版没有传送物，所以 travel 里没有它的行） |

断口表（`[nx] jump` 打印的，抄进 `scripts/walk-stair.cjs`）：`stair` 3 个（1.59/0.60 ×3）；
`stair_b` 13 个（上行 2 个：1.60/0.60、1.70/0.84；晶体岔路 5 个：0.80/0.30、0.80/0.10；巨踏步 6 个：0.50/0.82）。

## 待看（我自己还不满意的）

- **缝的「不可能」要主动去看**：直着走过去就是一段很顺的楼梯，只有**回头往下看**、或者**抬头看门洞上方**，
  才有那一下错乱。走过去的瞬间没有「我到了别处」的提示——这是缝的本性（不转场），不是 bug，但不够抓人。
- **「出发的那页纸在你上面」只做了一半**：真页在门下面十几米，透过门洞往斜下才看得见；高处那页「回声」
  是另放的一页（斜着浮着），更像一个装饰。要让它真成立，缝得能翻转高度——现有机制做不到（缝只绕竖轴转 ＋ 平移）。
- **巨踏步偏暗**：`violet_deep` 的顶面和侧面在背光时糊成一大块深色，远看是「一座黑金字塔」而不是六级台阶。
  想再把顶面调亮一档、或者加一点金（`gold` 只做点缀）。
- **柱心偏粗**：一摞圆板近看是「一坨」，不如远看有味道；也许改成更细的一根、或者干脆去掉只留楼梯。
- **只有约 1.9 圈**：螺旋半径 5.6m，一圈才 35m，0.30/0.80 的坡度一圈要升 13m，所以「绕几圈」其实不到两圈。
  要更多圈就得把半径收小（路会挤）或把坡度放缓（踏步更深）。
- **纸太大**：22 × 20.6m 的纸把整个下半都托住了，从楼梯上掉下来几乎总能落在纸上，
  `fall_to` 只在纸外面（或上半的虚空里）才触发得到。
- **迷你楼梯近看是「一条带」**：132 级合成 6 件，件与件之间有轮廓线、件内没有，凑近了看不太出是一级级台阶。
- 门框在近处很薄（1.32m 宽、0.30m 深），贴着看只剩两条竖边；门扇没做（这一版门洞是常开的）。
