# 天空主题

天空是一只跟着人走的球（`src/skybox.ts`），上面画的东西都在无穷远，只看方向。换主题时连带换掉雾色、天顶色、天光、地面反光、太阳色与晶体光——雾色就是地平线处的天色，地面才接得上。
天上的东西同样被像素化、量化到 16 色、描边；想让某块被描边，就在着色器里给它写一个编号（9000 起）和略近于 1000 的视深。细于半度左右的线不描边就会在像素化里消失。

## 怎么选

| 在哪 | 怎么写 |
|---|---|
| Blender 场景脚本 | `nx.atmosphere("halo")`，程序化的主题可给种子：`nx.atmosphere("dye", seed=7)`。放一个 `nx_type=atmosphere` 的空物体，属性 `nx_sky`（`dye:7`）。一个场景放一个；总图（atlas）里不生效 |
| 网页查询串 | `?sky=halo`、`?sky=dye:7`，覆盖场景里的设定，方便对比 |
| 调试键 | K 依次轮换（种子回到默认），当前主题显示在提示的最后一行 |

种子不写时为 1，所以同一个主题每次看到的一样，截图可以复现。只有标了「程序化」的主题认种子。

## 主题

| 名字 | 中文 | 方向 | 意图 |
|---|---|---|---|
| `blank` | 空白 | — | 原来的天色，雾粉到雾蓝，什么都没有。默认 |
| `halo` | 天环 | 巨构 · 头顶 | 以人为圆心、悬在天顶的五道细环：有的是整圈细线，有的分成稀疏的段，留大片空隙；分段的两道一顺一逆极慢地转 |
| `plumb` | 悬锤 | 巨构 · 头顶 · 程序化 | 天顶一个小环，从它垂下十三根细线，各在不同高度挂一枚菱形的锤（白或金），极慢地摆。种子定线的方位和长短 |
| `horizon` | 远碑 | 巨构 · 地平线 | 地平线上一圈比山还高的碑、门、拱和斜放的立方，近的一圈深、远的一圈浅；近的几块在慢慢挪。天色偏暖 |
| `lattice` | 天格 | 巨构 · 天花 | 天是一块极高的格栅天花，有些格子嵌着磨砂玻璃，少数是暖的；上面还有一层转了 45° 的、更稀的格。越近地平线越淡 |
| `dye` | 扎染 | 染梦 · 程序化 | 天是一顶扎染过的布篷，从一圈挂点垂下，下摆在挂点之间荡成弧（描边），弧下露出雾色的天。染底上留着白的防染纹：天顶一团白、放射的菊纹（可拧成螺旋），外加一圈圈扎线或鹿子点（实心小白点）；白纹往外洇一圈浅色，边沿参差。布在风里缓缓鼓动，明暗褶子扫过去，纹样跟着起伏。种子定挂点数、纹样组合、拧不拧、染色（雾蓝 / 玫粉 / 深紫） |
| `silk` | 绸 | 染梦 · 程序化 | 黄昏的天上横过 2–4 条染色的绸带，起伏与翻折沿着带子往前跑（几条朝不同方向飘），翻过来是另一面的颜色；正对着人的亮、侧过去的暗，一道光泽顺着带子滑过。被描边，像剪下来贴上去的。种子定条数、高度、起伏、翻折次数和配色 |
| `dawn` | 溶金 | 自由 | 看不见日头，只有地平线上一团暖雾和一两条化开的金色薄条。全场偏暖 |
| `night` | 星纸 | 自由 | 深紫的夜，星是大小不一的圆点（白、淡金、少数粉），少数带一圈柔光，偶尔一颗菱形或带短芒的；一条淡淡的星河斜着流过。全场变暗，晶体光调亮 |
| `flux` | 流质 | 虚空 | 整只天球（脚下也是）是一种慢慢翻涌的东西，像滴进奶里的墨、液态的珍珠母：浅紫、雾蓝、浅粉、白之间大片地流转，几条等值线是细的暗纹，被卷着走。没有地平线，给浮在虚空里的场景用 |
| `pale` | 素 | 巨构 | 几乎是白的天，什么也没有；天光压得低、太阳强，给纯白的建筑用——亮处和影子才分得开 |
| `overnight` | 一夜 | 窗景 · 博客 | 博客（AveritA的昼梦叙集）的那一夜，给现实的窗用（`nx.outlook(..., sky="overnight")`）。色板取博客主页故事板：浅冷灰 → 深蓝（深眠）→ 紫（异相）→ 晨光的暖白，压成四分钟一循环。地平线是一根线，节律跟着这一夜换（醒着细快、深眠长缓、异相锯齿、将醒出纺锤）；线下一排排是它的回声，越近越大越晚越淡；天上几道同心的淡拱（穹肋）；一枚琥珀色的点（博客唯一的异质色）顺着线从左走到右。颜色不取 NEXUS 的 16 色——窗里是那个站点自己的世界。种子错开时刻（1 ＝ 深眠，每加 1 往后八分之一夜）。当世界的天用时雾色对不上，只给窗用 |
| `scaffold` | 构造 | 窗景 · GitHub | GitHub（AveritA）的窗景——「可构造的」。一张制图纸样的天：浅暖灰的纸色、极淡的纸纹，铅灰的细线，地上几条收向灭点的透视引线。地平线上几座线框（塔架、门形的双拱框、立方格架、伸到半空的桁架桥；在 `src/scaffold.ts` 里按米搭好、算成方向写进着色器），一笔一笔按顺序画上去，一笔约三秒、画完停一停，搭到七八成又从最后一笔往回擦一些；画到哪儿，笔尖是一枚淡蓝的墨点。还没画上的边以极淡的虚线露着。站点卡片在左上，所以高的东西摆在正前方与右边。种子错开各座的进度。只给窗用 |

## 加一个主题

在 `src/skybox.ts` 的 `THEMES` 里加一项：`light`（雾色、天顶、天光等，省略的取空白的值）和 `glsl`（定义 `void theme(vec3 d, inout vec3 col, inout float id, inout float depth)`，`d` 是视线方向、y 朝上，`col` 进来时已是雾色→天顶的底色）。可用的 uniform：`uFogCol` `uZenith` `uSun` `uTime`（秒；`?freeze=1` 时为 0）、`uSeed`（种子，默认 1）、`uNight`（世界的昼夜，0 白天 … 1 夜里，见 blender.md「昼夜」；读了它就自己换夜色，没读的主题夜里整体压暗偏冷；入夜的天光写在主题的 `night` 里）、`tNoise`（256² 可平铺的值噪声，四个通道互不相干；`texture(tNoise, p / 256.0)` 一次取一层，比逐格算 hash 便宜得多）。着色器里的色板色用 `${lin('#d9aab5')}` 写。
沿方位角的频率取整数，绕一圈首尾才接得上。
天空每个像素都要跑一遍，别写多层 fbm 套循环；天球最后画，被世界挡住的像素不跑。改完用 `node scripts/skybench.cjs 主题,主题 [--shots]` 测帧率、隔几秒连拍三张看动起来的样子（`WORLD=`、`PITCH=` 可改世界与抬头角度）。`nx.py` 的 `atmosphere()` 文档串里把名字也补上。
