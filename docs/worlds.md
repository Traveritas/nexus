# NEXUS · 世界怎么做（草稿）

大方向：世界大概像 **Yume Nikki（梦日记）、Project Somnia、ENA: Dream BBQ** 这一类——一个个形状、大小、气质各不相同的梦，靠传送物连在一起，可以闲逛、迷路、撞见东西。
下面全是**倾向与选项**，不是规矩，挑着用、可以破。主域与世界的叫法见 [realms.md](realms.md)，搭场景的写法与数值见 [blender.md](blender.md)。

## 动手前

想清楚三件事：**形状**（下表哪一类，或哪几类叠在一起）、**边界**（走到最外面会怎样）、**出生点的第一眼**。
从第一眼的画面出发，再画地图；从俯视图出发容易画成建筑平面图——对称、有轴线、按功能分区，显得死板。

## 形状

| 类 | 是什么 | 适合 | 参考 |
|---|---|---|---|
| 一间 | 一个房间，或一件东西的内部；小而密，一眼看完 | 包裹、细看 | 梦日记的各个小屋 |
| 连房 | 一座建筑里几个房间、几层楼连着，看不见外面或只从缝里看见 | 来回绕、门后是什么 | 梦日记的室内世界；家家家 |
| 围起来的一片 | 有边的一块场景：四周高地、崖壁、墙、水围住，范围一眼看得出 | 一个完整的地方 | Proteus 的岛、A Short Hike |
| 迷宫 | 路分叉、回头、死胡同，走本身就是在找 | 迷路、发现、绕回原处 | 梦日记的 Number World |
| 大地 | 大到像开放世界的一片，里面塞满几个区、很多景象、很多去处 | 主域的门面，少做 | Project Somnia 的大地图 |
| 路 | 一条单向的长路，走本身就是内容，尽头可能什么也没有 | 过渡、期待、落空 | 梦日记的高速公路、长楼梯 |
| 竖向 | 一路往下或往上，深度就是进度 | 下沉、到达 | 下沉 · 井、白井 |
| 一瞥 | 极小，只为一个画面存在，看完就该走 | 惊一下、记住一个形象 | 梦日记的 FACE、Uboa |
| 玩法 | 一段自成一体的小玩法（跳台、追逐、小游戏），走完回到网里 | 换口味，少放 | 梦日记的 NASU；Celeste 式的平台 |
| 循环的大地 | 首尾相接，走出去从另一边回来。**只在想法需要「走不出去」时用**，用了也要往里放东西 | 迷路、空旷 | 梦日记的雪原、荒野；家的门外（原野） |

多数世界先从有边的或塞得满的想起。可以叠：一片 ＋ 一瞥（走着走着撞见一个画面）、连房 ＋ 会变（再来时多了一扇门）。

叠在任何形状上的：

- **会变**：再来时不一样了，或被开关、物品、昼夜、太阳改变。
- **远景**：远处有一样很大的东西，永远走不到（天空主题里的远碑、天环，或场景里很远的巨构）。
- **藏着的角**：没什么用、但让人想走过去的地方。

## 边界

| 手法 | 怎么回事 | 现在能不能做 |
|---|---|---|
| 封住 | 墙、井壁、玻璃——边界是建筑自己 | 能 |
| 围住 | 高地、崖壁、坡太陡上不去 | 能 |
| 悬崖 / 浮岛 | 边就是落差，掉下去回到出生点 | 能（掉到 −40m 以下回出生点） |
| 掉进别处 | 掉下去落进另一个世界——掉落本身是一种传送 | 要加：按世界指定掉落的去处 |
| 水 | 地被水围住，水本身是边 | 能（水不能走就行） |
| 雾里变淡 | 往外东西越来越稀、雾越来越浓 | 能（雾的远近跟着天空主题） |
| 循环 | 走出边界从另一边回来 | 能：`atmosphere(wrap=边长)` |
| 悄悄带回来 | 走得够远，人从另一个方向回到中心附近 | 要加 |
| 原地走 | 过了某个半径，人一直在走，周围却不再变化 | 要加；适合 ABYSS |

「底板到头就是虚空」看起来像没做完——除非虚空本身就是这个世界的意思（残片）。

## 倾向

- **一个机制不是一个世界**：光、影子、会变这些是调子；世界里还要有东西可看、有路可走、有地方可去。空旷要是这个世界的意思，不是缺省。
- **一个从远处就看得见的东西**，给人方向，也让人想走过去。
- **不对称**：轴线可以有，但别处处对称；偏一点、歪一点、缺一块。
- **尺度拉开**：世界之间大小可以差几十倍；有的只是一个房间，有的很大。
- **疏密有变化**：密的一团、空的一片、再密一团。
- **东西不必有用**：多数东西只是在那里。传送物、晶体、物品是少数。
- **路不只一条**，但也不必处处连通：死胡同、看得见走不到的地方都可以有。

## 出入口

世界之间靠**传送物**来往；有的世界里有**晶体**通往真实的站点。怎么放、怎么写见 blender.md「世界」。

- **出入口意象**：去哪个世界，通常就碰那个世界的东西（形态可以变，大小、立着躺着都行）。
- **来回成对**：A 里通往 B 的东西跟前，就是从 B 回来时落脚的地方。
- **回家**：每个世界用自己的一样东西回家，不必都一样。
- **传送物落在一样看得见的东西上**，不在空地上凭空传送（站进影子、光这类地上的形状也算看得见）。
- **数量不限**：可以只有一个出入口（死胡同，只能原路回去），也可以一个世界里塞满去处（建议平常1——2个，多的4个，重要的枢纽4个以上）。
- 晶体多放在偶然进来的人容易走到的地方。
