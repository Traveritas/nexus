# NEXUS · 世界的地图（草稿）

做正式世界时翻的参考：一个世界可以是什么形状、边界怎么收、怎么不做得死板。
这里全是**倾向与选项**，不是规矩，挑着用、可以破。主域与世界的叫法见 [realms.md](realms.md)，搭场景的数值见 [blender.md](blender.md)。

## 先想两件事

每个世界动手前写下两行（也可以写进 mockup 的 layout JSON：`shape`、`edge`）：

- **形状**：它是下面哪一类（或哪两类叠在一起）。
- **边界**：走到最外面会发生什么。

再写一句**出生点看到的第一个画面**，然后才画地图。从俯视图出发容易画成一张建筑平面图：对称、有轴线、按功能分区——那是 shallows-01 显得死板的主要原因。

## 形状

| 类 | 是什么 | 适合 | 参考 |
|---|---|---|---|
| 循环的大地 | 一大片首尾相接的地，走出去从另一边回来；里面散着几处东西、几个传送物 | 迷路、找东西、空旷 | 梦日记的大多数世界（雪原、荒野） |
| 箱庭 · 一间 | 一个房间，或一件放大的东西的内部 | 小而密、一眼看完 | 梦日记的各个小屋 |
| 箱庭 · 连房 | 几个房间、几层楼连起来 | 来回绕、门后是什么 | 梦日记的商场、学校 |
| 箱庭 · 一片 | 有边的一块场景（墙、悬崖、水、雾） | 一个完整的地方 | shallows-01 的多数方案 |
| 箱庭 · 大地 | 大到像开放世界的一片，里面有几个区 | 主域的门面、少做 | Project Somnia 的大地图 |
| 路 | 一条单向的长路，走本身就是内容，尽头可能什么也没有 | 过渡、期待、落空 | 梦日记的高速公路、长楼梯 |
| 竖井 / 高塔 | 一路往下或往上，深度就是进度 | 下沉、到达 | 下沉 · 井、云阶 · 断梯、白井 |
| 一瞥 | 极小，只为一个画面存在，看完就该走 | 惊一下、记住一个形象 | 梦日记的 FACE、Uboa |
| 玩法 | 一段自成一体的小玩法（跳台、追逐、小游戏），走完回到网里 | 换口味，少放 | 梦日记的 NASU；Celeste 式的平台 |
| 连片 | 同一主域里的几个世界直接走过去，不经传送 | 主域内的整体感 | realms.md 里提过 |

可以叠：**循环的大地 + 一瞥**（荒野里偶然撞见一个画面）、**箱庭 + 会变**（第二次来时房间多了一扇门）。

### 叠在任何形状上的

- **会变**：再来时不一样了，或被开关、物品、昼夜改变。入夜开关已经有了，可以接着发展。
- **远景**：远处有一样很大的东西，永远走不到（天空主题里的远碑、天环就是这一类，也可以是场景里放在很远的纸片或巨构）。
- **藏着的角**：没什么用、但让人想走过去的地方。

## 边界

| 手法 | 怎么回事 | 现在能不能做 |
|---|---|---|
| 封住 | 墙、井壁、温室的玻璃——边界是建筑自己 | 能 |
| 悬崖 / 浮岛 | 边就是落差，掉下去回到出生点 | 能（掉到 −40m 以下回出生点，`src/main.ts`） |
| 掉进别处 | 掉下去不是回出生点，而是落进另一个世界——掉落本身是一种传送 | 要加：按世界指定掉落的去处 |
| 雾里变淡 | 往外东西越来越少、雾越来越浓，最后只剩地面和雾，边界不显形 | 大体能；雾的远近现在跟着天空主题走（`skybox.ts` 的 `fogNear` / `fogFar`），要按世界单独调得加一项 |
| 水 / 海 | 地被水围住，水本身是边 | 能（水不能走就行） |
| 循环 | 走出边界从另一边回来，地是无缝的 | 有了：`atmosphere(wrap=边长)`，四周画复制、越过边界平移人（家的门外） |
| 悄悄带回来 | 走得够远，人从另一个方向回到中心附近，几何上并不真的相接 | 要加：越过某个半径时换位置（藏在雾里） |
| 原地走 | 过了某个半径，人一直在走，周围却不再变化（东西跟着人走） | 要加；不对劲的感觉，适合 ABYSS |

不管用哪种，**边上要有点东西**：越往外越稀，但不是零；地面一直延续到看不清的地方，远处留一样认得出的东西。
「底板到头就是虚空」看起来像没做完——除非虚空本身就是这个世界的意思（残片、无墙之屋）。

## 不死板的倾向

- **从看到的画面出发**，而不是从平面图出发。出生点看过去的第一眼最重要。
- **一个从远处就看得见的东西**，给人方向，也让人想走过去。
- **不对称**：轴线可以有，但别处处对称；偏一点、歪一点、缺一块。
- **尺度拉开**：世界之间大小可以差几十倍；有的只是一个房间，有的走不完。不要每个都是「家的 4~6 倍」。
- **疏密有变化**：密的一团、空的一大片、再密一团。空是有意留的，不是没做到。
- **东西不必有用**：多数东西只是在那里。传送物、晶体、物品是少数。
- **路不只一条**，但也不必处处连通：死胡同、看得见走不到的地方都可以有。
- **一个世界一个意象**（同 blender.md「世界」的出入口意象），其余的东西都围着它。
- **对着打开**：同一个世界里，近处是熟悉的日常物，远处 / 边上开始不对劲。
