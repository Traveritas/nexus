# NEXUS · UI

UI 不另起一套网页风格，和世界守同一套规矩：同样的像素尺度、同一块 16 色色板、剪纸的质感。

## 地基（`src/ui.ts`）

- **像素尺度**：UI 画在一张盖在画面上的低分辨率画布（`#ui`）上，1 个 UI 像素 ＝ 2 个屏幕像素（`UI_SCALE`），等于解析度场 1 级的格子。位置一律取整，不画半个像素。
- **颜色**：只用色板里的颜色（常用的收在 `C` 里：墨 `ink`、纸 `paper`、纸背 `back`、影子 `shadow`、系线 `thread`、纤维 `fibre`）。不做半透明的压暗或描边，要暗就换暗一档的色。
- **字**：缝合像素字体 12px（`public/fonts/`，OFL）。按 8 倍画大、在每个字像素中心取样，没有半透的边；`text(字, 色)` 返回缓存好的字图，`inkRows` 量墨迹的上下界，用来居中。
- **剪纸**：`paperMask` 给一张四边带几段 1 格缺口、四角各剪一格的形状（同一个种子形状固定）；`paper` 画纸面＋一圈墨线（可带纤维点），`paperShadow` 在右下压一格影子。纸的背面是空白的纸（`back`，与纸片的 `nx_back` 默认色同）。
- **全分辨率的例外**：凡是连着真实站点的东西（晶体的名字）不走像素 UI，保持全分辨率的平滑字。清晰的东西就是真实的东西。
- **现实的字**（`src/realtext.ts`）：连着真实站点的名字（晶体、一片夜的地图上的站点；窗景不挂名字，名字在推开窗后的站点卡片上）是和纸签相对的一套样子。纸签是梦里的：像素、不透明的纸、剪口、墨线、影子、系着线晃、一翻出来；现实的字是光里的：没有底，四角一副发丝细的取景角，一圈光晕，不翻面而是**对焦**——远时虚、字距散开、取景角张开，走近时收拢、清楚、取景角合上（`focus(f, a)`：f 是对焦，a 是不透明度，分开给，走到跟前化白时是清楚地淡掉）。上一行等宽小字的域名，下一行衬线的站名；拉丁字（Palatino）与汉字（Noto Serif SC）分开排、各用各的字距，交界处空一点，全大写的拉丁字字距放宽，间隔号「·」单独一段。
- **开场的「点击醒来」**还在梦里，是像素字：不淡入淡出，一个字一个字从浅档浮出来（雾 → 淡紫 → 墨），之后每个字在墨的三档之间呼吸，相位一个错一个；醒来时跟着木条一个个退回浅档收走。

## 中英（`src/i18n.ts`）

- 界面上的字都从 `STR` 取（`t('键')`），带数的写成函数（`night(n)`、`gotOn(n, 哪里)`）。跟着各自模块走的字用 `{ zh, en }`（`L`）：世界名 `WORLD_NAMES`、物品的 `name`/`desc`，用 `l(…)` 取。
- 场景里写死的字（Blender 的 `nx_title`、`nx_pose_title`）不改场景，按中文原文查 `SCENE` 表，纸签出来时 `tr(原文)` 换成当前语言；查不到照原样。新加的纸签字记得往 `SCENE` 里补一行。
- **不翻的**：连着真实站点的名字与站点自己的话（晶体、窗外的站点卡片）——清晰的东西就是真实的东西；调试信息、天的名字（调试用）。
- 语言存在 `nexus:settings` 的 `lang`；没存过看浏览器的语言（`zh*` 用中文，其余英文）。日记「设置」里切换，当场生效；纸签、开场的「点击醒来」下一次出来时换。
- 截图：`diary-shot.cjs` 两种语言各拍一遍；`NEXUS_LANG=en node scripts/ui-shot.cjs …` 拍英文的纸签。

## 窗前的站点卡片（`src/sitecard.ts`）

现实的窗（窗景 `outlook`，见 docs/blender.md）推开以后，眼睛凑到窗口往外看，卡片从画面里浮出来。

- **全分辨率**：卡片连着真实的站点，和晶体的名字一样是平滑字，不走像素 UI。字体与留白取那个站点自己的样子——博客是等宽的域名小字、衬线的站名、一道从左往右延展的细线、一句站点自己的话（主页的开篇问句）。
- **字色跟着窗里的天**：`WindowSky.tone(t)` 给出此刻窗里的底色与墨色；天亮时深墨、夜里浅墨，字下压一圈底色的光晕，压在流动的线上也读得清。
- **浮现**：淡入、细线延展、按键提示晚半拍出来；收起比浮现快（退回、进站时不留残影）。换一处时往换的方向滑开、窗外一亮（`resolve` 的白冲一下），亮到最白那一刻换掉天和卡片，再从另一边淡回来。
- **键**：A / D（← / →）换一处（只有一处时不显示）· E（Enter）进入 · S（Esc、↓、Backspace）退回；凑在窗口时别的键都不算。鼠标只带一点偏转（±7°），人不走。指针锁着时按 Esc，丢了锁也算退回。
- **测试**：`__nexus.gaze()` 看状态，`__nexus.outlooks()` 可以临时往里加一处试换景。

## 交互提示（`src/prompt.ts`）

一张系在东西上的小纸签：`[E] 标题`。看着按键型传送物时，从东西那里升起空白的背面，一翻成正面；移开视线压扁成一条边收走。纸签悬在东西上方，一根线垂到东西上、末端一个结，转头时慢半拍地晃。按 E 时键帽沉下去一格。

可调：`LIFT`（离东西多高）、弹簧 `k`/`c`、翻面速度 `IN_SPEED`/`OUT_SPEED`。

## 日记本（`src/diary.ts`，Tab）

- 一本真的 3D 书，在自己的小场景里画，画进 UI 分辨率的离屏图，最近邻铺到屏幕上。书摊平停稳时页面一个纹素正好对一个 UI 像素，所以页上的字是锐利的；翻开、翻页时是真 3D。
- 书的明暗只分三档：正对镜头的一面颜色原样不动，侧过去的面按 `AUTO_RAMP` 的暗档往下走一到两级（和世界的三色明暗同一套）。
- 打开时世界「犯困」（`Field.drowse`）：格子退到最粗一级，颜色整体暗一档；晶体照旧清醒。
- 指针锁着时用像素小箭头操作，没锁时跟着真鼠标；摊开期间人不走、视角不转、E/Q 不算。
- **索引贴**：没有目录页。书顶上从右半的纸叠里伸出一排彩色小纸条（记录 · 拾得 · 设置，淡粉、雾蓝、淡金），和书页在同一个平面上、一个纹素对一个 UI 像素；翻在哪一节，那张贴最高，悬停的冒出一格、字变玫瑰色；点一下翻过去。醒着时「拾得」那张淡下去、点不了。每次打开停在「记录」。
- **记录**：一个总账，不按夜分。左页：第 N 夜（每开一个新标签页算一夜）、此刻在哪、去过几处 · 走过几条路（`nexus:edges`）· 几处站点（`nexus:sites`）· 拾得几件，底下一行「醒来」（醒着时淡下去）；右页：去过的地方（梦里的，此刻所在的那处玫瑰色）。
- **拾得**：左页列出得到的东西，点名字拿起 / 收起；右页是放大的图、第几夜在哪得到、说明（汉字按字、拉丁字按词折行，写不下收成省略号）。
- **设置**（书的最后）：视角灵敏度、画面、语言、调试信息（存在 `localStorage` 的 `nexus:settings`；头一次进来是关的，关着时提示不出、调试键（1–6 · G · H · K）也都不认，飞行跟着收起来）；调试信息开着时多一行「清除存档」，点一下变成「再点一下清除」，再点就清掉 `nexus:` 开头的存档（设置留着）并重新载入——世界的连法改过以后，旧存档里走过的连接会在星图上留下不存在的线，用它清掉；隔一行一个 NEXUS——回到开场的标题，木条重新拼成字，再点一下醒来；用名字本身，不叫「返回主界面」。右页是操作说明。
- 加一节：写左右两个 `Draw` 函数（画在 148×196 的页上，返回可点的区域），加进 `pages`、`ORDER` 与 `TABS`，在 `click` 里处理它的区域。

## 物品

### 已经有的（骨架）

- **只在梦里**：在现实（`src/worlds.ts` 的 `REALITY`）里身上的东西拿不出来——不能举（Q）、不能环绕（F 只出一张「醒着，什么也没带出来」的纸签）、拿着的那件也收着；日记的「拾得」淡下去、点不了。回到梦里一切照旧。

- **定义**：一件物品一个模块 `src/items/<名字>.ts`，在 `src/items/item.ts` 的 `ITEMS` 里登记。模块给出名字、说明、`need`/`collect`、像素小图 `icon()`（得到时的卡片、日记都用它）、拿在手里的 3D 模型 `held()`、可选的世界里与环绕展示时的样子 `world()`、可选的 `check()`（条件型）与 `bloom()`（用到底时发生的事）。模型都以米为单位，用世界的材质；会动的用「器物」材质（`charm`，三档受光直接取三枚色板色，不铺世界纹素格，跟着镜头走或自己转都不会让纹样游动）。
- **摆放**：场景里 `nx.item(...)`（`nx_type=item`，见 docs/blender.md），只标在哪、怎么得到。`pick` 走近看着它、纸签「拾起」、按 E；`reach` 走进范围就得到；`custom` 由物品的 `check()` 判断。已经得到的不再摆出来。物品写了 `world()` 就摆它自己的模型；没写就是一张正面朝人、左右轻摆、上下浮动的纸片（每米 16 像素）。
- **得到时的默认演出**（`src/items/system.ts`）：东西变成一张剪纸卡片，从原处翻着飞到眼前，四周一下子解析清楚（给解析度场加一个源），下面挂「得到了 · 名字」；停一会儿缩小飞进右下角，那里的小日记闪三下。前半段人不走。
- **拿在手里**：一次一件，平时收着；短按 Q（0.22 秒内松开）从画面右下（手边）举起来 / 收下；按住 Q 超过这个时间窗开始用（按下时就先举起来，不等判断；举到位后才开始用），松开回到按下前的样子——收着时按住用，松开就收回去。打开日记、环绕、换到现实时收下。它是真正的 3D：画在手边场景 `items.hand` 里，管线在世界画完后清掉深度再画进同一张图（不会插进墙里），再一起像素化、落色板、描边（`pipeline.render` 的 `overlay`）。手里没东西时，得到的第一件自动拿起。
- **环绕展示**（按住 F）：身上的东西排成一道弧，围在眼前齐眼高的地方，人不走、视角照转；世界犯困（格子退粗、暗一档），正看着的那件清醒过来（解析度场多一个源；犯困在源附近不生效）、挂上名字；松开 F 拿起它。身上没东西时只出一张「身上还没有东西」的纸签。
- **存档**：`localStorage` 的 `nexus:items`（有哪些、各在第几夜哪个世界得到、手里拿着哪件）。
- **日记「拾得」页**：列出得到的东西，点名字拿起 / 收起；右页是放大的图、第几夜在哪得到、说明。
- **测试**：`window.__nexus.placeItem(id, x, y, z, mode?)` 在当前世界临时摆一件，`__nexus.items.reset()` 忘掉所有物品；`node scripts/items-shot.cjs` 走一遍家里茶几上的一片夜 → 拾起 → 演出 → 按住 Q 使用 → 按住 F 环绕 → 日记。
- **第一件：一片夜**（`src/items/night.ts`；日记里的说明是「一片奇特的晶体，你透过它看到的是什么呢？」；id 仍是 `compass`，存档和场景里都这么叫；摆在家里客厅的茶几上，浮在上方绕竖轴慢慢晃，世界里放大 1.6 倍）：从一大块夜空上崩下来的一片——细长、两头尖，上沿是弧形断口，下沿是笔直的断边，6mm 厚。
  - 面（自己的着色器）：里面是最暗的那一色。星不贴在面上，而在它后面很远：每颗星有一个世界里的方向，透过碎片这扇窗看过去——四周一圈按碎片此刻在画面上的宽度压进去（正前方在中间，身后的在两头），高低按碎片的高度压扁；JS 里把方向投成 NDC，着色器按管线的格子画（`shared.uCellPx`、`shared.uViewPx`），和世界的格子对齐。碎片在手里晃、换角度，星不跟着动；转身时星从一头滑进来、从另一头滑出去。出入口的星同地图（`exitsOf`）：站点金（菱形）、去过的白（十字）、没去过的淡紫（一格）、通往别的主域的冷绿（十字），偶尔亮一下；背景星 14 颗：一格、最暗的几色，世界里固定的方向，按世界名撒，偶尔灭一会儿。
  - 断边：器物材质（`charm`，紫 · 淡紫 · 雾白三档受光），和面同一个编号，折角那里按凸棱亮一档——一两格宽的亮棱，手一晃沿边滑过去。不投影（`userData.noShadow`）。
  - 用（按住 Q）：碎片转正对着人，开始发抖、越抖越厉害；面上 7 条裂纹（每条 3 段，雾蓝一格宽）一段段长出来，每多一条停 0.05 秒、一胀；松开时裂纹跟着缩回去。用到底：停 0.07 秒，裂纹发白变粗，然后「啪」地变成激活的样子——六片偏宽的三角（`TRIS`）乱叠在一起：每片一条边朝外（大致贴着一个近乎圆的外圈，各自斜一点、远近不一），第三个顶点指向中心或越过中心，所以外轮廓是一圈有错台、小凹口的折线，没有尖往外戳；整簇按 `CLUSTER`（0.82）缩放，横着和碎片差不多宽、竖着高得多（星的窗口竖着高 `ACTIVE_TALL` 倍）。几片前后错开 2.5mm 一层（同一个编号，不描黑线），每片的正反面按重心坐标（`bary` 属性，`withEdges`）描一格宽的淡紫边——只描朝着画面左上的那几条（像光从一边来，片转动时哪条边被描也跟着变），上面那片的边压在下面那片的面上，像几层碎晶片叠着；侧边用亮一档的器物材质。摆开用弹簧（冲过头一点再回来）；激活着时每片主要沿外边来回滑（±1.4cm）、朝外进出一点、稍微转（±0.045 弧度）、胀缩（±4%），轮廓和里面的线一直在错动；整簇慢慢晃。地图从手边暗下去、铺满画面（见下）。
  - 激活着时：先松开 Q，再按住，几片往中间收、越抖越厉害；用到底时停一拍，0.16 秒合回一整片（裂纹没了、一胀），地图收起。地图因为别的原因收起（换世界）时自己合上。用到底一次以后要先松开，按着也不长裂纹、不抖、不触发。
- **使用不一定是捏**：Q 的提示是「举起 · 用」（短按举起，按住用），每件怎么用（捏、按、转……）由它自己的 `held()` 动作表现；`press` 只是用到了几成。

### 方向

- **是什么**：带效果的实物，一般不是传统物品。一次只拿一件，平时收着，用的时候（按住 Q）举到眼前。
- **效果**：目前只做改变「自己」的（视角、移动、手里的东西、看到的东西）。改变世界规则的效果以后若要做，只在新场景里做。
- **在哪**：只有部分世界的某些地方有，一个世界最多一件。
- **怎么得到**：自由度要高——拾取、完成某些条件、到达某些地点都可以；每件得到时有各自的演出。
- **节奏**：必要的物品容易拿到；特效、玩具一类作为收藏品，藏得深、条件难。

## 一片夜的地图（`src/mapview.ts`）

- **开合**：拿着一片夜用到底，世界从手边那一点暗下去（`Field.dim`：圆里每一格按暗档走两级，边缘按格子抖开，格子不变粗），扩满整个画面后星星一颗颗亮起。开着时照常走、转头；再用到底一次，暗色缩回手边；换世界时直接收起。
- **星是连续的光**：画在全分辨率的 `#glow` 画布上（`mix-blend-mode: screen`），一颗亮核、两层光晕、渐隐的星芒；亮度慢慢呼吸，偶尔星芒一长；亮起时星芒先冲出去再收回。**星光落到世界上是像素的**：每颗星周围按格子撤回暗下去的档（外圈一档、里圈两档回到原色），边缘按格子抖开（`Field.glow`）。暗圈里不描亮棱。
- **本世界**：每个出入口（传送物）与站点（晶体）一颗星，隔着墙也看得见；不标物品。站点：金，最大，另有一对慢慢转的斜芒；去过的世界的出口：白，雾蓝的晕；没去过的：暗紫，一点微光，没有芒。远处（10m 外）小一号；画面外的贴在屏幕边上（抬头时不贴）。
- **正看着的那颗**（离画面中心最近、60 个 UI 像素以内）挂一张纸签，只写通往哪里：出口「→ 浅滩」，没去过的「→ ？」；站点的名字连着真实的站点，用全分辨率的平滑字（`#maplabel`）。
- **通往别的主域**：本世界里通往另一个主域的出入口是冷绿的星，外面套一圈断成两截、慢慢转的环（星光那层一圈细线，像素层再画一圈 1 格的冷绿，亮处也看得见）；纸签写「→ 旧梦 · 旧家」，没去过的「→ 旧梦 · ？」。
